**选择结构让程序能"做判断"：如果满足条件就做 A，否则做 B。**

### if 语句 -- 最基本的判断

**生活中：** 如果明天下雨，我就带伞。
**代码里：**

```c
if (天气 == 下雨) {
    带伞();
}
```

![10](/learn/c-language/charts/10.png)

最简单的 if：**

```c
if (条件) {
    // 条件为"真"时，执行这里的代码
}
// 条件为"假"时，直接跳过这个代码块
```

**带 else 的二选一：**

```c
if (年龄 >= 18) {
    printf("成年人\n");
} else {
    printf("未成年人\n");
}
```

就像："如果年龄 ≥ 18，输出成年人，否则输出未成年人"。两个分支只走其中一个。**注意：if中还可以嵌套if**

**多分支：一连串的判断**

```c
if (score >= 90) {
    printf("优秀\n");
} else if (score >= 80) {
    printf("良好\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

执行流程：从上到下依次判断，**哪个条件先为真，就执行哪个分支，后面的不再判断**。如果 85 分，走 `score >= 80` 这个分支（输出"良好"），不会再去判断 `score >= 60`。

**什么是"真"和"假"？**

- 在 C 语言里，**非零就是真**，**0 就是假**
- `1`、`-5`、`100` 都是真
- `0` 是假
- `3 > 2` 结果是 `1`（真），`3 < 2` 结果是 `0`（假）

### 关系运算符 -- 做比较的

| 运算符  | 含义   | 注意                     |
|---|---|---|
| `==` | 等于   | **两个等号！一个等号 `=` 是赋值！** |
| `!=` | 不等于  | `!` 在 C 语言里表示"非"       |
| `>`  | 大于   |                        |
| `<`  | 小于   |                        |
| `>=` | 大于等于 |                        |
| `<=` | 小于等于 |                        |

**最常见的错误（新手必犯）：**

```c
if (a = 3)  // ❌ 这是赋值！把 3 赋给 a，然后条件永远为真
if (a == 3) // ✅ 这才是判断 a 是否等于 3
```

### 逻辑运算符 -- 组合多个条件

| 运算符  | 含义     | 怎么记              |
|---|---|---|
| `&&` | 与（AND） | 两个条件**都满足**才为真   |
| `||` | 或（OR） | **至少一个**满足就为真   |
| `!`  | 非（NOT） | **取反**，真的变假，假的变真 |

```c
// 判断一个人是否适合献血
if (age >= 18 && weight >= 50) {
    printf("可以献血\n");  // 年龄≥18 并且 体重≥50
}

// 判断成绩是否优秀或良好
if (score >= 80 || award == 1) {
    printf("可以评奖学金\n");  // 成绩≥80 或者 有获奖
}

// 判断是否不是周末
if (!(day == 6 || day == 7)) {
    printf("工作日\n");  // 今天不是周六也不是周日
}
```

**短路特性（了解一下就行）：**
- `a && b`：如果 `a` 已经是假了，`b` 就不会再算（因为"与"只要有一个假就是假，没必要再看了）
- `a || b`：如果 `a` 已经是真了，`b` 就不会再算（因为"或"只要有一个真就是真）

### switch 语句 -- 多选一

当你要根据一个变量的**具体值**做不同处理时，switch 比 if-else if 更清晰：

```c
switch (day) {
    case 1:
        printf("星期一\n");
        break;       // 不要漏！
    case 2:
        printf("星期二\n");
        break;
    case 3:
        printf("星期三\n");
        break;
    case 4:
    case 5:
        printf("周四或周五\n");  // 多个 case 可以共享一段代码
        break;
    default:
        printf("其他\n");       // 以上都不匹配时走这里
        break;
}
```

**break 的作用和为什么不能漏：**
`break` 表示"跳出 switch"。如果没有 break，程序会**穿透**（fall-through）到下一个 case 继续执行。比如 `day = 1`，如果 case 1 后面没有 break，会输出"星期一"，然后继续输出"星期二"，"星期三"... 直到遇到 break 才停。

### 条件运算符 `? :` -- 简写的 if-else

适合只有两个分支、且操作很简单的情况：

```c
int max = (a > b) ? a : b;
//          条件 ? 真的时候取这个 : 假的时候取这个
// 如果 a > b，max = a；否则 max = b
```
