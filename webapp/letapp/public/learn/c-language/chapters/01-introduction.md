### 什么是程序？什么是编程？

你可以把"程序"理解成**给电脑下达的一组指令**。就像你告诉朋友"先出门 → 左转 → 走100米 → 到超市"，电脑也需要你一步一步告诉它该做什么。而"编程"就是用一种电脑能听懂的语言（编程语言），把这些步骤写下来。

### 什么是 C 语言？

C 语言是 1972 年由一个叫 Dennis Ritchie 的人发明的，是一种**编程语言**。它的特点是：
- 运行速度快（离硬件近）
- 功能强大（能写操作系统、数据库这些底层软件）
- 语法简洁（关键字不多，容易学）
很多现代语言（C++、Java、Python）都借鉴了 C 语言的语法。学会 C 语言，学其他语言会轻松很多。

### 编译型语言 vs 解释型语言

电脑只能看懂 **0 和 1（机器码）**，你写的 C 代码它看不懂，需要一个"翻译官"。
- **编译型（C 语言是这种）**：写完所有代码后，用编译器**一次性**翻译成机器码，然后再运行。就像你写完整封信后，一次性翻译成英文。
- **解释型（比如 Python）**：写一行，翻译一行，执行一行。就像你边说中文边有人同步翻译成英文。
编译型的好处是运行速度快，缺点是修改代码后要重新编译。

### C 程序长什么样？

```c
#include <stdio.h>    // 第1行：引入标准输入输出库

int main() {           // 第2行：主函数，程序从这里开始
    printf("Hello\n");  // 第3行：在屏幕上打印 Hello
    return 0;          // 第4行：告诉系统"程序正常结束了"
}                      // 第5行：函数结束
```

逐行解释：
- `#include <stdio.h>`：这叫**预处理指令**。告诉编译器"我要用 printf 这个功能，请把相关的代码包含进来"。`stdio` = Standard Input Output（标准输入输出），`.h` = header（头文件）。**没有这行，printf 就不能用。**
- `int main()`：`main` 是"主函数"，每个 C 程序**必须有一个**，程序从这里开始执行。`int` 表示这个函数执行完会返回一个整数。
- `printf("Hello\n")`：在屏幕上显示文字。`\n` 是"换行符"，相当于按了一下回车键。
- `return 0`：返回 0 表示程序正常结束。返回非 0 表示出了错误。
- `{}`：花括号圈出一块代码，表示"这些代码是一个整体"。
- `;`（分号）：每条语句结束都要有分号，就像中文句子结尾要句号。**漏掉分号是最常见的错误之一。**

### 从写代码到运行的全过程

```
你写的代码 (hello.c)
        ↓  【编译】编译器翻译
目标文件 (hello.obj)
        ↓  【链接】链接器把你的代码和系统库拼接
可执行文件 (hello.exe)
        ↓  【运行】双击或命令行执行
屏幕输出：Hello
```

1. **编译**：编译器把你的 `.c` 文件翻译成机器能看懂的目标文件 `.obj`
2. **链接**：链接器把你的目标文件和 C 语言自带的库文件合并成一个 `.exe` 文件
3. **运行**：双击运行这个 `.exe`，或者在命令行里执行
