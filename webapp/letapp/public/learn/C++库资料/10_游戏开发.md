# 游戏开发库详解

## 一、SDL2 — 底层多媒体库

### 概述
Simple DirectMedia Layer 2，提供底层的窗口、音视频、输入、OpenGL 上下文管理。很多商业游戏和引擎（如 Valve 的游戏）使用 SDL2。

### 安装
vcpkg: `vcpkg install sdl2 sdl2-image sdl2-mixer sdl2-ttf`

### 初始化与窗口

```cpp
#include <SDL2/SDL.h>

int main(int argc, char* argv[]) {
    // 初始化
    if (SDL_Init(SDL_INIT_VIDEO | SDL_INIT_AUDIO) < 0) {
        SDL_Log("初始化失败: %s", SDL_GetError());
        return -1;
    }

    // 创建窗口
    SDL_Window* window = SDL_CreateWindow("My Game",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN);

    // 创建渲染器
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED | SDL_RENDERER_PRESENTVSYNC);

    // 主循环
    bool quit = false;
    SDL_Event event;
    while (!quit) {
        // 处理事件
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) quit = true;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.sym == SDLK_ESCAPE) quit = true;
        }

        // 清屏
        SDL_SetRenderDrawColor(renderer, 0, 0, 0, 255);  // 黑色
        SDL_RenderClear(renderer);

        // 绘制
        SDL_SetRenderDrawColor(renderer, 255, 0, 0, 255); // 红色
        SDL_Rect rect = {100, 100, 200, 150};
        SDL_RenderFillRect(renderer, &rect);

        // 渲染
        SDL_RenderPresent(renderer);
        SDL_Delay(16);  // ~60 FPS
    }

    // 清理
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 键盘输入


### 纹理加载与绘制

```cpp
#include <SDL2/SDL_image.h>

// 加载图片为纹理
SDL_Texture* loadTexture(SDL_Renderer* renderer, const char* path) {
    SDL_Surface* surface = IMG_Load(path);
    if (!surface) return nullptr;
    SDL_Texture* texture = SDL_CreateTextureFromSurface(renderer, surface);
    SDL_FreeSurface(surface);
    return texture;
}

SDL_Texture* tex = loadTexture(renderer, "player.png");
SDL_Rect dst = {x, y, w, h};
SDL_RenderCopy(renderer, tex, nullptr, &dst);  // 绘制纹理
```

## 二、SFML — 简单易用的 2D 游戏框架

### 概述
SFML（Simple and Fast Multimedia Library）比 SDL2 更易用，封装更面向对象，适合 2D 游戏快速开发。

### 安装
vcpkg: `vcpkg install sfml`

### Hello SFML

```cpp
#include <SFML/Graphics.hpp>

int main() {
    sf::RenderWindow window(sf::VideoMode(800, 600), "SFML Game");
    window.setFramerateLimit(60);

    sf::CircleShape shape(50.0f);  // 半径50的圆
    shape.setFillColor(sf::Color::Green);
    shape.setPosition(100, 100);

    sf::RectangleShape rect(sf::Vector2f(100, 50));
    rect.setFillColor(sf::Color::Red);

    while (window.isOpen()) {
        sf::Event event;
        while (window.pollEvent(event)) {
            if (event.type == sf::Event::Closed)
                window.close();
            if (event.type == sf::Event::KeyPressed &&
                event.key.code == sf::Keyboard::Escape)
                window.close();
        }

        // 移动
        if (sf::Keyboard::isKeyPressed(sf::Keyboard::Left))
            shape.move(-1, 0);

        window.clear(sf::Color::Black);
        window.draw(shape);
        window.draw(rect);
        window.display();
    }
    return 0;
}
```

## 三、SDL2 vs SFML 对比

| 特性 | SDL2 | SFML |
|------|------|------|
| 语言 | C | C++（面向对象） |
| 学习曲线 | 陡 | 平 |
| 性能 | 高 | 高 |
| 文档 | 官方文档详细 | 官方教程友好 |
| 扩展支持 | SDL_image/mixer/ttf/network | sf::Graphics/Audio/Network/Window |
| OpenGL | 直接支持 | 直接支持 |
| 手机/游戏机 | 广泛支持 | 支持有限 |
| 适用场景 | 商业游戏、跨平台 | 快速原型、学习、2D 游戏 |

**选型建议：**
- 初学者 / 快速原型 / 2D 小游戏 → **SFML**
- 商业级别 / 需要底层控制 / 跨平台 → **SDL2**
- 数学建模可视化（简易 2D 演示） → **SFML**（上手最快）
