# 深度学习推理库详解

## 一、LibTorch（PyTorch C++ 版本）

### 概述
LibTorch 是 PyTorch 的 C++ 前端，用于在 C++ 环境中加载训练好的 PyTorch 模型进行推理。

### 安装
1. 从 https://pytorch.org 下载 LibTorch（选择 C++ / CUDA）
2. 解压后包含 `include/`、`lib/`、`bin/`

### CMake 配置

```cmake
cmake_minimum_required(VERSION 3.18)
project(MyApp)

# 设置 LibTorch 路径
set(CMAKE_PREFIX_PATH "D:/path/to/libtorch")
find_package(Torch REQUIRED)

add_executable(app main.cpp)
target_link_libraries(app ${TORCH_LIBRARIES})
target_include_directories(app PRIVATE ${TORCH_INCLUDE_DIRS})
```

### 核心类型：torch::Tensor

```cpp
#include <torch/torch.h>
using namespace torch;

// 创建张量（对标 torch.Tensor）
Tensor t1 = tensor({1, 2, 3});                     // 1D int
Tensor t2 = tensor({{1,2},{3,4}});                 // 2D int
Tensor t3 = ones({3, 4}, kFloat);                  // 3×4 全1 float
Tensor t4 = zeros({2, 3}, kDouble);                // 2×3 全0 double
Tensor t5 = randn({100, 10});                      // 正态分布
Tensor t6 = full({3, 3}, 5.0);                     // 全部填充 5.0
Tensor t7 = eye(5);                                // 5×5 单位矩阵

// 属性
t.dtype();       // 数据类型
t.sizes();       // 形状（返回 IntArrayRef）
t.numel();       // 总元素个数
t.dim();         // 维度
t.device();      // CPU/CUDA

// 形状操作
t.view({-1, 10});          // reshape
t.reshape({-1, 10});       // reshape（可能复制数据）
t.transpose(0, 1);         // 转置
t.permute({1, 0, 2});      // 重排维度
t.unsqueeze(0);            // 增加维度
t.squeeze(0);              // 压缩维度
t.flatten();               // 展平

// 数学运算
t1 + t2;                       // 逐元素加
t1.mul(t2);                    // 乘
t1.matmul(t2);                 // 矩阵乘
t1.mm(t2);                     // 二维矩阵乘（同 matmul）
t1.dot(t2);                    // 向量点积

t.sum();                       // 求和
t.mean();                      // 均值
t.std();                       // 标准差
t.max();                       // 最大值
t.min();                       // 最小值
t.abs();                       // 绝对值
t.sqrt();                      // 平方根
t.exp();                       // 指数
t.log();                       // 对数
t.sigmoid();                   // sigmoid
t.softmax(1);                  // softmax（沿维度1）
t.clamp(0, 1);                // 裁剪

// GPU
t = t.to(torch::kCUDA);        // 移到 GPU
t = t.to(torch::kCPU);         // 移回 CPU
bool gpu = t.is_cuda();
```

### 定义模型

```cpp
// 使用 Sequential（简单）
struct Net : torch::nn::Module {
    Net() {
        fc1 = register_module("fc1", torch::nn::Linear(784, 256));
        fc2 = register_module("fc2", torch::nn::Linear(256, 10));
    }
    Tensor forward(Tensor x) {
        x = torch::relu(fc1->forward(x));
        x = fc2->forward(x);
        return x;  // 返回 logits
    }
    torch::nn::Linear fc1{nullptr}, fc2{nullptr};
};
```

### 加载预训练模型推理

```cpp
#include <torch/script.h>  // JIT 推理

int main() {
    // 加载 TorchScript 模型（从 Python 导出）
    torch::jit::script::Module module;
    module = torch::jit::load("model.pt");
    module.to(torch::kCUDA);
    module.eval();

    // 输入数据
    std::vector<torch::jit::IValue> inputs;
    inputs.push_back(torch::randn({1, 3, 224, 224}).to(torch::kCUDA));

    // 推理
    torch::Tensor output = module.forward(inputs).toTensor();
    auto max_val = output.argmax(1);

    std::cout << "预测类别: " << max_val.item<int>() << "\n";
    return 0;
}
```

### Python 导出 TorchScript

```python
import torch

class MyModel(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = torch.nn.Linear(784, 10)
    def forward(self, x):
        return self.fc(x)

model = MyModel()
model.eval()
example = torch.randn(1, 784)
traced = torch.jit.trace(model, example)
traced.save("model.pt")
```

## 二、ONNX Runtime

### 概述
微软的跨平台深度学习推理引擎，支持 PyTorch/TensorFlow/Keras 导出的 ONNX 模型。

### 安装
vcpkg: `vcpkg install onnxruntime`

### 使用

```cpp
#include <onnxruntime/core/session/onnxruntime_cxx_api.h>

int main() {
    Ort::Env env(ORT_LOGGING_LEVEL_WARNING, "test");
    Ort::SessionOptions opts;
    opts.SetIntraOpNumThreads(4);

    // 加载 ONNX 模型
    Ort::Session session(env, "model.onnx", opts);

    // 获取输入输出信息
    Ort::AllocatorWithDefaultOptions allocator;
    auto input_name = session.GetInputNameAllocated(0, allocator);
    auto output_name = session.GetOutputNameAllocated(0, allocator);

    // 准备输入
    std::vector<int64_t> input_shape{1, 3, 224, 224};
    std::vector<float> input_data(1 * 3 * 224 * 224, 0.5f);
    auto memory_info = Ort::MemoryInfo::CreateCpu(OrtArenaAllocator, OrtMemTypeDefault);
    Ort::Value input_tensor = Ort::Value::CreateTensor<float>(
        memory_info, input_data.data(), input_data.size(),
        input_shape.data(), input_shape.size());

    // 推理
    const char* input_names[] = {input_name.get()};
    const char* output_names[] = {output_name.get()};
    auto output_tensors = session.Run(Ort::RunOptions{nullptr},
        input_names, &input_tensor, 1,
        output_names, 1);

    // 获取输出
    float* output_data = output_tensors[0].GetTensorMutableData<float>();
    // 处理 output_data...
    return 0;
}
```

### Python 导出 ONNX

```python
import torch
import torch.onnx

model = MyModel()
dummy = torch.randn(1, 784)
torch.onnx.export(model, dummy, "model.onnx",
    input_names=["input"], output_names=["output"],
    dynamic_axes={"input": {0: "batch"}})
```

## 三、TensorFlow C++ API

### 概述
TensorFlow 官方提供 C++ API，但比 LibTorch 复杂且文档较少。常用于 TF 模型的部署。

### 构建 TensorFlow C++ 库
需要从源码用 Bazel 构建，较复杂。推荐用 LibTorch 或 ONNX Runtime 替代。

---

## 库选择指南

| 库 | 训练 | 推理 | 模型格式 | 安装难度 | 推荐场景 |
|------|------|------|---------|---------|---------|
| LibTorch | 支持 | 支持 | TorchScript | 中 | PyTorch 用户，C++ 训练+推理 |
| ONNX Runtime | 不支持 | 支持 | ONNX | 低 | 多框架模型部署 |
| TensorFlow C++ | 不支持 | 支持 | SavedModel/PB | 高 | TF 生态用户 |

**数学建模推荐：** LibTorch（Python 训练 → C++ 部署，最流畅的体验）
