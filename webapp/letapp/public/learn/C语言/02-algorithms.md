### 什么是算法？

**算法 = 解决问题的步骤。** 举个生活中的例子：泡面。
泡面的"算法"：
1. 烧水
2. 撕开泡面包装
3. 放入调料包
4. 倒入开水
5. 等 3 分钟
6. 开吃
这就是一个算法。它有明确的步骤，每一步都能执行，最后得到了一碗面。

### 算法的五大特性

一个好的算法必须满足这五点：

| 特性      | 含义           | 泡面例子               |
|---|---|---|
| **有穷性** | 步骤有限，不会无限进行  | 只等 3 分钟，不会一直等      |
| **确定性** | 每一步都明确，没有歧义  | "倒开水"很明确，不是说"倒点液体" |
| **可行性** | 每一步都能实际做到    | 烧水、撕包装都能做到         |
| **输入**  | 可以有 0 个或多个输入 | 输入：泡面、开水、调料包       |
| **输出**  | 至少有一个输出      | 输出：一碗泡面            |

### 三种基本程序结构（重中之重）

所有程序，无论多复杂，都由这三种结构组合而成：
**1. 顺序结构** -- 从上到下，一步一步执行

```
步骤1 → 步骤2 → 步骤3
```

就像跟着菜谱做菜：第一步切菜，第二步开火，第三步炒菜。
**2. 选择结构** -- 根据条件，选择不同的路

```
如果下雨 → 打伞出门
如果没下雨 → 不打伞出门
```

就像出门前看天气决定带不带伞。
**3. 循环结构** -- 重复做某件事，直到满足条件才停下

```
反复：跑步（直到跑完5圈才停）
```

就像跑步跑 5 圈，每跑一圈检查"到 5 圈了吗"，没到就继续跑。

### 算法的表示方法

怎么把算法记录下来给别人看？有5种常用方式：

| 方式          | 优点               | 缺点         |
|---|---|---|
| **自然语言**    | 最直观，谁都能看懂        | 容易有歧义，不够精确 |
| **流程图**     | 图形化，一目了然         | 画起来比较麻烦    |
| **伪代码**     | 接近代码但不要语法，重点表达逻辑 | 需要一点编程基础   |
| **N-S 流程图** | 结构紧凑，没有箭头        | 不够灵活       |
| **计算机语言** | 可直接运行，精准无歧义 | 需掌握编程语言，普通人难读懂 |
