# latex式子

求和符号

```latex
$\sum_{i=1}^{n} a_i$
```

德尔塔x

``` latex
大写
$\Delta x$
小写
$\delta x$
```

分子分母格式

``` latex
$\frac{a}{b}$  % 行内公式
\[ \frac{a}{b} \]  % 行间公式
```

行间求导公式

```latex
\[ \frac{\partial u}{\partial t}(x_i,t_j)=\frac{1}{\Delta t}[u(x_i,t_{j+1})-u(x_i,t_j)] \]
```

圈数字

```latex
\usepackage{pifont} % 在导言区添加
\ding{172} → ①
\ding{173} → ②
\ding{174} → ③
...
\ding{181} → ⑩
```

上下角标

``` latex
$u_{i}^{j}$  % 默认上下标对齐左侧
```

希腊数字符号

```latex
$\alpha, \beta, \gamma, \delta$  % 小写：α, β, γ, δ  
$\Gamma, \Delta, \Theta, \Lambda$ % 大写：Γ, Δ, Θ, Λ

```
