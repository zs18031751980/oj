### 什么是程序？什么是编程？

你可以把"程序"理解成**给电脑下达的一组指令**。就像你告诉朋友"先出门 → 左转 → 走100米 → 到超市"，电脑也需要你一步一步告诉它该做什么。而"编程"就是用一种电脑能听懂的语言（编程语言），把这些步骤写下来。

### 什么是 C 语言？

C 语言是 1972 年由一个叫 Dennis Ritchie 的人发明的，是一种**编程语言**。它的特点是：
- 运行速度快（离硬件近）
- 功能强大（能写操作系统、数据库这些底层软件）
- 语法简洁（关键字不多，容易学）
很多现代语言（C++、Java、Python）都借鉴了 C 语言的语法。学会 C 语言，学其他语言会轻松很多。

### 编译型语言 vs 解释型语言

电脑只能看懂 **0 和 1（机器码）**，你写的 C 代码它看不懂，需要一个"翻译官"。
- **编译型（C 语言是这种）**：写完所有代码后，用编译器**一次性**翻译成机器码，然后再运行。就像你写完整封信后，一次性翻译成英文。
- **解释型（比如 Python）**：写一行，翻译一行，执行一行。就像你边说中文边有人同步翻译成英文。
编译型的好处是运行速度快，缺点是修改代码后要重新编译。

### C 程序长什么样？

```c
#include <stdio.h>    // 第1行：引入标准输入输出库

int main() {           // 第2行：主函数，程序从这里开始
    printf("Hello\n");  // 第3行：在屏幕上打印 Hello
    return 0;          // 第4行：告诉系统"程序正常结束了"
}                      // 第5行：函数结束
```

逐行解释：
- `#include <stdio.h>`：这叫**预处理指令**。告诉编译器"我要用 printf 这个功能，请把相关的代码包含进来"。`stdio` = Standard Input Output（标准输入输出），`.h` = header（头文件）。**没有这行，printf 就不能用。**
- `int main()`：`main` 是"主函数"，每个 C 程序**必须有一个**，程序从这里开始执行。`int` 表示这个函数执行完会返回一个整数。
- `printf("Hello\n")`：在屏幕上显示文字。`\n` 是"换行符"，相当于按了一下回车键。
- `return 0`：返回 0 表示程序正常结束。返回非 0 表示出了错误。
- `{}`：花括号圈出一块代码，表示"这些代码是一个整体"。
- `;`（分号）：每条语句结束都要有分号，就像中文句子结尾要句号。**漏掉分号是最常见的错误之一。**

### 从写代码到运行的全过程

```
你写的代码 (hello.c)
        ↓  【编译】编译器翻译
目标文件 (hello.obj)
        ↓  【链接】链接器把你的代码和系统库拼接
可执行文件 (hello.exe)
        ↓  【运行】双击或命令行执行
屏幕输出：Hello
```

1. **编译**：编译器把你的 `.c` 文件翻译成机器能看懂的目标文件 `.obj`
2. **链接**：链接器把你的目标文件和 C 语言自带的库文件合并成一个 `.exe` 文件
3. **运行**：双击运行这个 `.exe`，或者在命令行里执行

### 什么是算法？

**算法 = 解决问题的步骤。** 举个生活中的例子：泡面。
泡面的"算法"：
1. 烧水
2. 撕开泡面包装
3. 放入调料包
4. 倒入开水
5. 等 3 分钟
6. 开吃
这就是一个算法。它有明确的步骤，每一步都能执行，最后得到了一碗面。

### 算法的五大特性

一个好的算法必须满足这五点：

| 特性      | 含义           | 泡面例子               |
|---|---|---|
| **有穷性** | 步骤有限，不会无限进行  | 只等 3 分钟，不会一直等      |
| **确定性** | 每一步都明确，没有歧义  | "倒开水"很明确，不是说"倒点液体" |
| **可行性** | 每一步都能实际做到    | 烧水、撕包装都能做到         |
| **输入**  | 可以有 0 个或多个输入 | 输入：泡面、开水、调料包       |
| **输出**  | 至少有一个输出      | 输出：一碗泡面            |

### 三种基本程序结构（重中之重）

所有程序，无论多复杂，都由这三种结构组合而成：
**1. 顺序结构** -- 从上到下，一步一步执行

```
步骤1 → 步骤2 → 步骤3
```

就像跟着菜谱做菜：第一步切菜，第二步开火，第三步炒菜。
**2. 选择结构** -- 根据条件，选择不同的路

```
如果下雨 → 打伞出门
如果没下雨 → 不打伞出门
```

就像出门前看天气决定带不带伞。
**3. 循环结构** -- 重复做某件事，直到满足条件才停下

```
反复：跑步（直到跑完5圈才停）
```

就像跑步跑 5 圈，每跑一圈检查"到 5 圈了吗"，没到就继续跑。

### 什么是数据类型？

C 语言里，不同的数据需要不同的"容器"来装。就像生活里：
- 整数（你的年龄）--> 用 `int`（整数类型）
- 小数（你的身高 1.75）--> 用 `float` 或 `double`（浮点类型）
- 单个字符（你的性别 'M'）--> 用 `char`（字符类型）
为什么要有数据类型？因为电脑内部，整数和小数的存储方式不同，告诉电脑数据类型，电脑才能正确存储和处理。

| 类型       | 存什么       | 占多大内存 | 举例                       |
|---|---|---|---|
| `int`    | 整数（没有小数点） | 4 字节  | 0, 1, -3, 100, 9999      |
| `float`  | 小数（精度较低）  | 4 字节  | 3.14, -0.5, 1.0          |
| `double` | 小数（精度更高）  | 8 字节  | 3.14159265358            |
| `char`   | 单个字符      | 1 字节  | 'a', 'Z', '0', ' ', '\n' |

`float` 和 `double` 的区别：`float` 大约能精确到小数点后 6-7 位，`double` 能精确到 15-16 位。

### 什么是变量？

变量就是一个有名字的盒子，里面可以放一个数据，而且以后可以换。**

```
+-----+
|  10 |  ← 盒子里现在装的是 10
+-----+
  ↑
  a    ← 这个盒子的名字叫 a
```

![5](/learn/c-language/charts/5.png)

使用变量分两步：**先声明（造盒子），再使用（放东西/取东西）**

```c
int a;        // 声明：造一个名叫 a 的盒子，只能装整数
a = 10;       // 赋值：把 10 放进盒子 a 里
int b = 20;   // 声明和赋值可以合写在一起
```

**命名规则：**
- 只能用字母、数字、下划线 `_`
- **不能以数字开头**（`1a` 不行，`a1` 可以）
- 不能用 C 语言的关键字（比如 `int`、`for`、`if` 不能当变量名）
- 区分大小写（`A` 和 `a` 是两个不同的变量）

### 什么是常量？

![4](/learn/c-language/charts/4.png)

**常量就是永远不变的值。** 一旦设定就不能改。

```c
#define PI 3.14159    // 定义符号常量 PI，以后代码里写 PI 就等于 3.14159
int a = 100;          // 100 也是一个常量（字面常量）
```

为什么用常量？比如你程序里到处用到圆周率 3.14159，写 10 次 3.14159，万一要改精度，就要改 10 处。如果用 `#define PI 3.14159`，以后改一处就行了。

### 运算符详解

**算术运算符（做数学运算的）：**

| 运算符 | 功能  | 举例       | 结果         |
|---|---|---|---|
| `+` | 加法  | `3 + 5`  | `8`        |
| `-` | 减法  | `10 - 3` | `7`        |
| `*` | 乘法  | `4 * 5`  | `20`       |
| `/` | 除法  | `10 / 3` | `3`（整数除法！） |
| `%` | 取余数 | `10 % 3` | `1`        |

**整数除法的坑（非常重要）：**
- `10 / 3 = 3`（不是 3.333，因为两边都是整数，结果自动砍掉小数）
- `10.0 / 3 = 3.333`（有一个是小数，结果就是小数）
- 想要精确结果，至少有一个数写成小数形式：`10 / 3.0`
**取余 `%` 的应用场景：**
- 判断奇偶：`n % 2 == 0` 就是偶数，`n % 2 != 0` 就是奇数
- 取个位数：`123 % 10 = 3`
- 判断倍数：`n % 7 == 0` 表示 n 是 7 的倍数
**赋值运算符 `=`（不是等于！）：**

```c
int a = 10;   // 把 10 赋值给 a
a = a + 5;    // a 原来是 10，加上 5，变成 15，再放回 a
a += 5;       // 上面的简写，a = a + 5 等价于 a += 5
a -= 3;       // a = a - 3
a *= 2;       // a = a * 2
a /= 4;       // a = a / 4
a %= 10;      // a = a % 10
'a'%2=1       //'a'是字符，先转换为ASCLL编码‘a’=97,97%2=1
```

`++` 和 `--`（自增自减）：

```c
int a = 5;
a++;    // a 变成 6（相当于 a = a + 1）
a--;    // a 变成 5（相当于 a = a - 1）
```

![6](/learn/c-language/charts/6.png)

类型转换：**

```c
int a = 3;
double b = 7.0 / a;   // 自动转换：a 自动变成 3.0 再算，结果是 2.333
int c = (int)3.9;      // 强制转换：直接砍掉小数，c = 3（不是四舍五入！）
```

### printf 和 scanf -- 输入和输出

**printf -- 在屏幕上显示信息：**

```c
printf("我的年龄是 %d 岁\n", 20);
//        格式控制符 ↑
//        %d 会被后面的 20 替换
//        输出：我的年龄是 20 岁
```

![7](/learn/c-language/charts/7.png)

![8](/learn/c-language/charts/8.png)

常用格式控制符：

| 符号     | 用途       | 举例                      | 输出         |
|---|---|---|---|
| `%d`   | 整数       | `printf("%d", 42)`      | `42`       |
| `%f`   | 浮点数      | `printf("%f", 3.14)`    | `3.140000` |
| `%.2f` | 保留 2 位小数 | `printf("%.2f", 3.14)`  | `3.14`     |
| `%c`   | 单个字符     | `printf("%c", 'A')`     | `A`        |
| `%s`   | 字符串      | `printf("%s", "hello")` | `hello`    |
| `\n`   | 换行       | `printf("A\nB")`        | A（换行）B     |

**scanf -- 从键盘读取用户输入：**

```c
int age;
scanf("%d", &age);
//     ↑    ↑
//     格式  &表示"把输入存到 age 的地址里"
//     输入一个整数，存到 age 变量中
```

**为什么 scanf 要加 `&`？**
你可以这样理解：scanf 需要知道"把数据存到内存的哪个位置"。`&age` 就是"age 这个变量在内存中的门牌号"。没有门牌号，快递员（scanf）就不知道往哪送。
**多个输入：**

```c
int a, b;
scanf("%d%d", &a, &b);  // 输入 3 5（中间用空格隔开），a=3, b=5
```

### 字符与 ASCII 码

电脑只能存数字，不能存字母。那怎么存字符呢？答案是：**给每个字符编一个数字编号**。这个编号表叫 ASCII 码。
常用 ASCII 码：
- `'A'` = 65，`'B'` = 66 ... `'Z'` = 90
- `'a'` = 97，`'b'` = 98 ... `'z'` = 122
- `'0'` = 48，`'1'` = 49 ... `'9'` = 57
- `' '`（空格）= 32
**大小写转换的技巧：**
- 大写转小写：`'A' + 32 = 'a'`（因为 'a'(97) - 'A'(65) = 32）
- 小写转大写：`'a' - 32 = 'A'`

**选择结构让程序能"做判断"：如果满足条件就做 A，否则做 B。**

### if 语句 -- 最基本的判断

**生活中：** 如果明天下雨，我就带伞。
**代码里：**

```c
if (天气 == 下雨) {
    带伞();
}
```

![10](/learn/c-language/charts/10.png)

最简单的 if：**

```c
if (条件) {
    // 条件为"真"时，执行这里的代码
}
// 条件为"假"时，直接跳过这个代码块
```

**带 else 的二选一：**

```c
if (年龄 >= 18) {
    printf("成年人\n");
} else {
    printf("未成年人\n");
}
```

就像："如果年龄 ≥ 18，输出成年人，否则输出未成年人"。两个分支只走其中一个。**注意：if中还可以嵌套if**

**多分支：一连串的判断**

```c
if (score >= 90) {
    printf("优秀\n");
} else if (score >= 80) {
    printf("良好\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

执行流程：从上到下依次判断，**哪个条件先为真，就执行哪个分支，后面的不再判断**。如果 85 分，走 `score >= 80` 这个分支（输出"良好"），不会再去判断 `score >= 60`。

**什么是"真"和"假"？**

- 在 C 语言里，**非零就是真**，**0 就是假**
- `1`、`-5`、`100` 都是真
- `0` 是假
- `3 > 2` 结果是 `1`（真），`3 < 2` 结果是 `0`（假）

### 关系运算符 -- 做比较的

| 运算符  | 含义   | 注意                     |
|---|---|---|
| `==` | 等于   | **两个等号！一个等号 `=` 是赋值！** |
| `!=` | 不等于  | `!` 在 C 语言里表示"非"       |
| `>`  | 大于   |                        |
| `<`  | 小于   |                        |
| `>=` | 大于等于 |                        |
| `<=` | 小于等于 |                        |

**最常见的错误（新手必犯）：**

```c
if (a = 3)  // ❌ 这是赋值！把 3 赋给 a，然后条件永远为真
if (a == 3) // ✅ 这才是判断 a 是否等于 3
```

### 逻辑运算符 -- 组合多个条件

| 运算符  | 含义     | 怎么记              |
|---|---|---|
| `&&` | 与（AND） | 两个条件**都满足**才为真   |
| `||` | 或（OR） | **至少一个**满足就为真   |
| `!`  | 非（NOT） | **取反**，真的变假，假的变真 |

```c
// 判断一个人是否适合献血
if (age >= 18 && weight >= 50) {
    printf("可以献血\n");  // 年龄≥18 并且 体重≥50
}

// 判断成绩是否优秀或良好
if (score >= 80 || award == 1) {
    printf("可以评奖学金\n");  // 成绩≥80 或者 有获奖
}

// 判断是否不是周末
if (!(day == 6 || day == 7)) {
    printf("工作日\n");  // 今天不是周六也不是周日
}
```

**短路特性（了解一下就行）：**
- `a && b`：如果 `a` 已经是假了，`b` 就不会再算（因为"与"只要有一个假就是假，没必要再看了）
- `a || b`：如果 `a` 已经是真了，`b` 就不会再算（因为"或"只要有一个真就是真）

### switch 语句 -- 多选一

当你要根据一个变量的**具体值**做不同处理时，switch 比 if-else if 更清晰：

```c
switch (day) {
    case 1:
        printf("星期一\n");
        break;       // 不要漏！
    case 2:
        printf("星期二\n");
        break;
    case 3:
        printf("星期三\n");
        break;
    case 4:
    case 5:
        printf("周四或周五\n");  // 多个 case 可以共享一段代码
        break;
    default:
        printf("其他\n");       // 以上都不匹配时走这里
        break;
}
```

**break 的作用和为什么不能漏：**
`break` 表示"跳出 switch"。如果没有 break，程序会**穿透**（fall-through）到下一个 case 继续执行。比如 `day = 1`，如果 case 1 后面没有 break，会输出"星期一"，然后继续输出"星期二"，"星期三"... 直到遇到 break 才停。

### 条件运算符 `? :` -- 简写的 if-else

适合只有两个分支、且操作很简单的情况：

```c
int max = (a > b) ? a : b;
//          条件 ? 真的时候取这个 : 假的时候取这个
// 如果 a > b，max = a；否则 max = b
```

**循环 = 让某段代码反复执行。** 这是 C 语言中最重要的部分之一。

### for 循环 -- 最常用的循环

**什么时候用 for？** 当你**知道要循环多少次**的时候。

```c
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
// 输出：1 2 3 4 5
```

拆解 for 的三个部分：

```
for (初始化; 条件; 更新) {
         ↓      ↓     ↓
    造一个计数器i=1  i<=5才继续  每次结束后i加1
```

**执行过程（一步一步看）：**

```
第1次：i=1, 检查1<=5? 是 → 打印1 → i变成2
第2次：i=2, 检查2<=5? 是 → 打印2 → i变成3
第3次：i=3, 检查3<=5? 是 → 打印3 → i变成4
第4次：i=4, 检查4<=5? 是 → 打印4 → i变成5
第5次：i=5, 检查5<=5? 是 → 打印5 → i变成6
第6次：i=6, 检查6<=5? 否 → 循环结束！
```

### while 循环 -- 先判断再执行

**什么时候用 while？** 当你**不知道要循环多少次**，只知道"满足某个条件就继续"。

```c
int password;
while (1) {                // 1 永远为真，所以这个循环会一直执行
    scanf("%d", &password);
    if (password == 1234) {
        printf("密码正确！\n");
        break;              // break 跳出循环
    }
    printf("密码错误，重新输入\n");
}
```

**关键区别**：while 先判断条件，如果一开始就为假，循环体一次都不执行。

### do-while 循环 -- 先执行再判断

```c
int n;
do {
    printf("请输入一个正整数：");
    scanf("%d", &n);
} while (n <= 0);  // 如果输入的不是正数，就重新输入
```

**for vs while vs do-while 选择：**
- 知道循环次数 → **for**
- 先判断后执行，可能一次都不执行 → **while**
- 至少执行一次 → **do-while**

### break 和 continue

- **break**：直接**跳出整个循环**，后面的所有轮次全部不执行了
- **continue**：**跳过这一次**，进入下一轮

```c
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;     // i=5 时直接退出循环，6-10 都不会执行
    printf("%d ", i);       // 输出：1 2 3 4
}

for (int i = 1; i <= 10; i++) {
    if (i == 5) continue;   // i=5 时跳过本次，继续下一轮
    printf("%d ", i);       // 输出：1 2 3 4 6 7 8 9 10（跳过了5）
}
```

### 嵌套循环 -- 循环里面套循环

**外层循环走一轮，内层循环走完所有轮。**
举例：打印星号三角形

```
*
**
***
****
*****
```

外层控制行数（5 行），内层控制每行打几个星号：

```c
for (int i = 1; i <= 5; i++) {        // 外层：5 行
    for (int j = 1; j <= i; j++) {    // 内层：第 i 行打 i 个星号
        printf("*");
    }
    printf("\n");                     // 每行打完换行
}
```

执行过程：
- i=1：内层 j 从 1 到 1，打 1 个 `*`
- i=2：内层 j 从 1 到 2，打 2 个 `*`
- i=3：内层 j 从 1 到 3，打 3 个 `*`
- 以此类推

### 常见算法模式

**累加模式：** 设一个变量存总和，循环里不断往里加

```c
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum = sum + i;   // 或者 sum += i;
}
// sum = 5050
```

**计数模式：** 设一个计数器，满足条件就加 1

```c
int count = 0;
for (int i = 1; i <= 100; i++) {
    if (i % 3 == 0) {
        count++;    // 是 3 的倍数就计数
    }
}
// count = 33（1-100 中有 33 个 3 的倍数）
```

**最大值查找：** 逐个比较，保留最大的

```c
int max = a[0];
for (int i = 1; i < n; i++) {
    if (a[i] > max) {
        max = a[i];
    }
}
```

**函数 = 把一段代码"打包"，起个名字，以后想用就直接喊名字。**

### 为什么需要函数？

假设你写了一个"求最大值"的逻辑，在程序里 5 个不同的地方都要用。如果没有函数，你要复制粘贴 5 次同样的代码。如果逻辑要修改，就要改 5 处。
有了函数：把逻辑写在一个地方（定义函数），5 个地方只写 `max(a, b)` 调用它。逻辑改了，只改一处就行。**代码更简洁、更好维护。**

### 函数的定义和调用

```c
// 定义函数（造工具）
int add(int a, int b) {
    return a + b;
}
//  ↑     ↑ ↑    ↑
//  返回值  函数名  参数（原材料）
//  类型

int main() {
    int result = add(3, 5);  // 调用函数（使用工具）
    // add(3, 5) 就是把 3 和 5 交给 add 函数处理
    // 它会返回 3+5=8，存到 result 里
    printf("%d\n", result);   // 输出 8
}
```

**定义函数的四个部分：**
1. **返回值类型**：函数执行完返回什么类型的数据（`int`、`float`、`void`=不返回）
2. **函数名**：给函数起个有意义的名字（`add`、`max`、`sort`...）
3. **参数列表**：函数需要什么原材料（可以有 0 个、1 个或多个）
4. **函数体**：花括号里的具体逻辑

### 形参和实参（概念很重要）

```c
int add(int a, int b) {  // a, b 叫"形参"（形式参数）
    return a + b;          // 相当于占位符
}

int main() {
    int x = 3, y = 5;
    int r = add(x, y);     // x, y 叫"实参"（实际参数）
    // 调用时：x 的值(3) 复制给 a，y 的值(5) 复制给 b
}
```

**关键理解：** 实参的值**复制**给形参，形参和实参是两个独立的变量。形参在函数里怎么改，都不影响外面的实参。这叫**值传递**。

```c
void try_change(int x) {
    x = 999;  // 只改了形参 x，外面的实参完全不受影响
}

int main() {
    int a = 10;
    try_change(a);
    printf("%d\n", a);  // 输出 10（没变！）
}
```

### 递归 -- 函数自己调用自己

**递归 = 函数内部调用自己。** 听起来很怪？其实生活中也有递归。
举个例子：你问第 5 个人"你排第几"，第 5 个人说"我不知道，你问第 4 个人"，第 4 个人说"你问第 3 个人"... 一直问到第 1 个人，他说"我排第 1"。然后答案一层层传回来：第 2 = 第 1 + 1 = 2，第 3 = 第 2 + 1 = 3... 第 5 = 5。
**递归的两个要素（缺一不可）：**
1. **递归关系**：大问题怎么拆成小问题（`n! = n × (n-1)!`）
2. **终止条件**：最小的那个问题能直接回答（`1! = 1`）

```c
int factorial(int n) {
    if (n <= 1) {
        return 1;          // 终止条件：1的阶乘 = 1
    }
    return n * factorial(n - 1);  // 递归：n! = n × (n-1)!
}

// factorial(3) 的执行过程：
// factorial(3) = 3 * factorial(2)
//               = 3 * (2 * factorial(1))
//               = 3 * (2 * 1)
//               = 6
```

### 变量的作用域和生存期

| 类型       | 在哪定义         | 能被谁访问    | 什么时候生、什么时候死      |
|---|---|---|---|
| **局部变量** | 函数内部         | 只有本函数能访问 | 函数被调用时诞生，函数结束时死亡 |
| **全局变量** | 函数外部（所有函数外面） | 所有函数都能访问 | 程序启动时诞生，程序结束时死亡  |

```c
int g = 100;           // 全局变量

void func() {
    int x = 5;         // 局部变量，只在 func 里能用
    g = 200;           // 可以访问和修改全局变量
}

int main() {
    int y = 10;        // 局部变量，只在 main 里能用
    // x 在这里访问不到！
}
```

**`static` 局部变量** -- 函数结束后不销毁，下次调用时还保留上次的值：

```c
void counter() {
    static int count = 0;  // 只在第一次调用时初始化为 0
    count++;
    printf("%d\n", count);
}

int main() {
    counter();  // 输出 1
    counter();  // 输出 2（count 保留了上次的值 1，加 1 变 2）
    counter();  // 输出 3
}
```

> **对应视频：**

**指针是 C 语言最重要也最难的概念。用简单的话说：指针就是"地址"。**

### 内存和地址

电脑内存可以想象成一排排的**小格子**，每个格子有：
- 一个**地址**（门牌号）
- 里面存的**数据**（住的人）

```
地址：  0x1000  0x1004  0x1008  0x100C  ...
数据：    10      20      30      40
名字：     a       b       c       d
```

当你写 `int a = 10;`，电脑就找一块空格子，把 10 放进去，然后记住了"格子 a 在地址 0x1000"。

### 什么是指针

**指针变量 = 专门用来存地址的变量。** 普通变量存数据，指针变量存地址。

```c
int a = 10;       // 普通变量 a，里面存的是数据 10
int *p = &a;      // 指针变量 p，里面存的是 a 的地址
```

```
普通变量 a：          指针变量 p：
+--------+         +----------+
|   10   |  ←----  | 0x1000  |  （p 里存的是 a 的地址）
+--------+         +----------+
 地址0x1000           地址0x2000
```

**两个关键符号：**
- `&a` -- **取地址**，获取变量 a 的门牌号（`&` = "address of"）
- `*p` -- **解引用**，通过指针 p 里存的地址，找到那个格子，取出里面的值（`*p` 等价于 `a`，值为 10）

```c
int a = 10;
int *p = &a;

printf("%d\n", *p);   // 10（通过 p 找到 a，取出 10）
*p = 20;              // 通过 p 找到 a，把值改成 20
printf("%d\n", a);    // 20（a 被改了）
```

### 指针有什么用？

**最大的用处：通过函数修改变量的值。**
前面学过，值传递时形参不影响实参。但如果传的是地址，就能通过地址直接修改外面的变量：

```c
// 错误的交换：值传递，交换无效
void swap_wrong(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
    // 交换的是形参 a、b，外面的实参完全不受影响
}

// 正确的交换：传指针（地址传递）
void swap(int *pa, int *pb) {
    int temp = *pa;   // temp = *pa，即 temp = 外面那个变量的值
    *pa = *pb;         // 把外面另一个变量的值给第一个
    *pb = temp;         // temp 给第二个
    // 通过地址直接修改了外面的变量！
}

int main() {
    int x = 3, y = 7;
    swap(&x, &y);      // 传的是 x 和 y 的地址
    printf("x=%d, y=%d\n", x, y);  // x=7, y=3，交换成功！
}
```

**类比：** 值传递就像你把一张照片给朋友，朋友在照片上画画，不影响你手上的原件。地址传递就像你把家里的地址给朋友，朋友直接去你家改了东西。

### 指针与数组

数组名就是首元素的地址，所以指针和数组天然有关：

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;    // p 指向 a[0]，等价于 p = &a[0]
```

```
数组 a：[10] [20] [30] [40] [50]
          ↑
          p（指向 a[0]）
```

指针加减法的含义：

```c
p + 1    // 不是地址 +1 字节，而是指向下一个元素！
*(p + 2) // 等价于 a[2]，值为 30
p[3]     // 指针也能用下标，等价于 *(p + 3)，值为 40
```

**`p + i` 实际移动了多少字节？** 取决于元素大小。`int` 占 4 字节，所以 `p + 1` 实际地址加了 4 字节（跳过一个 int 的大小）。

### 动态内存分配

前面的数组大小都是写死的（`int a[100]`）。如果运行时才知道需要多大呢？用 `malloc`（memory allocate 的缩写）：

```c
int n;
scanf("%d", &n);   // 用户输入需要多少个整数
int *p = (int *)malloc(n * sizeof(int));  // 动态申请内存
//            ↑
//    把申请到的内存转换成 int* 类型（指向 int 的指针）
```

```c
if (p == NULL) {       // malloc 失败会返回 NULL
    printf("内存不足！\n");
    return 1;
}

// 现在可以像数组一样使用 p[0] ~ p[n-1] 了
for (int i = 0; i < n; i++) {
    scanf("%d", &p[i]);
}

free(p);    // 用完必须释放！不释放就是"内存泄漏"
p = NULL;  // 释放后把指针置空，防止误用（野指针）
```

**malloc 和数组的区别：**

| 数组   | malloc     |                  |
|---|---|---|
| 大小   | 固定（写死在代码里） | 动态（运行时决定）        |
| 内存位置 | 栈（自动管理）    | 堆（手动管理）          |
| 释放   | 函数结束自动回收   | 必须 `free()` 手动释放 |

**前面用的 int、float、char 都是"基础类型"，只能存一个数据。结构体让你可以"自定义类型"，把多个不同类型的数据打包在一起。**

### 结构体 -- 把相关数据打包

假设你要描述一个学生：有名字（字符串）、年龄（整数）、成绩（小数）。用基础类型要三个独立变量，容易搞混。用结构体可以打包成一个整体：

```c
struct Student {
    char name[20];   // 名字，字符数组
    int age;         // 年龄，整数
    float score;     // 成绩，浮点数
};
```

这样 `struct Student` 就成了一个新类型，就像 int 一样用。
**创建和初始化：**

```c
struct Student s1 = {"Alice", 20, 95.5};  // 创建时就赋值
struct Student s2;                          // 先创建，后赋值
s2.age = 21;
s2.score = 88.5;
strcpy(s2.name, "Bob");  // 字符串不能直接 = 赋值，要用 strcpy
```

**访问成员用 `.`（点号）：**

```c
printf("Name: %s, Age: %d, Score: %.1f\n", s1.name, s1.age, s1.score);
// 输出：Name: Alice, Age: 20, Score: 95.5
```

### 结构体指针

指向结构体的指针，用 `->` 访问成员（比 `(*p).` 方便）：

```c
struct Student s = {"Alice", 20, 95.5};
struct Student *p = &s;

printf("%s\n", p->name);    // Alice（(*p).name 的简写）
printf("%d\n", (*p).age);   // 20（和 p->age 一样）
```

`.` 和 `->` 的区别：
- **`s.name`**：s 是结构体变量本身，用 `.`
- **`p->name`**：p 是指向结构体的指针，用 `->`

### 结构体数组

数组里每个元素都是一个结构体，就像一个 Excel 表格：

```c
struct Student class[3] = {
    {"Alice", 20, 95},
    {"Bob", 21, 88},
    {"Charlie", 20, 76}
};

// 用循环访问
for (int i = 0; i < 3; i++) {
    printf("%s: %.1f\n", class[i].name, class[i].score);
}
```

### 共用体 union -- 所有成员共享同一块内存

```c
union Data {
    int i;
    float f;
    char str[4];
};
```

和结构体的区别：struct 的成员各有各的内存，union 的成员**共用同一块内存**。同一时间只能存一种类型的值。

```c
union Data d;
d.i = 42;         // 存了一个整数
printf("%d\n", d.i);   // 42
d.f = 3.14;       // 现在存了浮点数，之前的 42 被覆盖了
printf("%d\n", d.i);   // 输出一个奇怪的数（因为那块内存现在存的是 3.14 的二进制形式）
```

### 枚举 enum -- 给数字起名字

```c
enum Color { RED, GREEN, BLUE };
// RED = 0, GREEN = 1, BLUE = 2（自动从 0 开始编号）

enum Weekday { MON = 1, TUE, WED, THU, FRI, SAT, SUN };
// MON = 1, TUE = 2, ... SUN = 7（从指定值开始编号）

enum Color c = RED;    // c 的值就是 0
```

好处：`MON` 比 `1` 更有可读性，代码里写 `day == MON` 比 `day == 1` 更清楚。

### typedef -- 给类型起别名

```c
typedef struct Student {
    char name[20];
    int age;
} Stu;   // 给 struct Student 起了个短名叫 Stu

Stu s = {"Alice", 20};  // 不用再写 struct Student 了
```

### 链表基础

**数组的问题**：大小固定，创建后不能增减。
**链表**：每个节点存数据 + 下一个节点的地址，像一条链子一样串起来。大小可以随时增减。

```c
struct Node {
    int data;          // 存数据
    struct Node *next; // 指向下一个节点的指针
};
```

```
[10] → [20] → [30] → NULL
 ↑
head（链表的头，从这里开始）
```

核心操作：
- **创建节点**：用 `malloc` 分配内存，初始化数据和 next 指针
- **遍历链表**：从 head 开始，`p = p->next` 一个一个往后走，直到 `p == NULL`
- **插入节点**：修改前后节点的指针指向
- **删除节点**：把要删的节点跳过，然后 `free` 释放内存

### 文件的基本概念

- **文本文件**：存的是人类可读的文字（如 `.txt`、`.c`）
- **二进制文件**：存的是计算机内部的格式，人类直接看是乱码（如 `.exe`、`.jpg`）

### FILE 指针

C 语言用 `FILE *` 类型的指针来操作文件。可以理解为"文件句柄"，你通过它和文件打交道：

```c
FILE *fp;
```

### fopen -- 打开文件

```c
fp = fopen("data.txt", "r");
//   文件名       打开模式
```

**常用打开模式：**

| 模式     | 含义   | 文件不存在时 | 文件已存在时     |
|---|---|---|---|
| `"r"`  | 只读   | 报错     | 从头开始读      |
| `"w"`  | 只写   | 创建新文件  | **清空原内容！** |
| `"a"`  | 追加写  | 创建新文件  | 在末尾追加      |
| `"r+"` | 读+写  | 报错     | 从头开始       |
| `"w+"` | 读+写  | 创建新文件  | 清空原内容      |
| `"rb"` | 二进制读 | 报错     | 从头开始读      |
| `"wb"` | 二进制写 | 创建新文件  | 清空原内容      |

**每次用 fopen 都要检查是否成功：**

```c
FILE *fp = fopen("data.txt", "r");
if (fp == NULL) {
    printf("文件打开失败！\n");
    return 1;
}
```

### fclose -- 关闭文件

**用完必须关闭！** 不关闭文件可能导致数据丢失。

```c
fclose(fp);
```

### fprintf / fscanf -- 格式化读写

和 `printf` / `scanf` 几乎一样，只是多了个文件指针参数：

```c
// 写入文件
fprintf(fp, "Name: %s, Score: %d\n", "Alice", 95);

// 从文件读取
char name[20];
int score;
fscanf(fp, "%s %d", name, &score);
```

### fgetc / fputc -- 逐字符读写

```c
fputc('A', fp);          // 往文件写一个字符 'A'
int ch = fgetc(fp);      // 从文件读一个字符
// 读到文件末尾，fgetc 返回 EOF（End Of File，值为 -1）
```

### fgets / fputs -- 字符串读写

```c
fputs("Hello", fp);      // 写一个字符串到文件（不自动加换行）
char buf[100];
fgets(buf, 100, fp);      // 从文件读一行（最多 99 个字符）
// fgets 会把换行符 \n 也读进来，遇到换行或读完 99 字符就停
```

### fwrite / fread -- 二进制读写

直接把内存里的数据按字节写入文件：

```c
struct Student s = {"Alice", 20, 95.5};
fwrite(&s, sizeof(struct Student), 1, fp);  // 把 s 写入文件
//       ↑数据地址   ↑每个元素大小        ↑元素个数

struct Student t;
fread(&t, sizeof(struct Student), 1, fp);   // 从文件读一个结构体到 t
```

二进制读写比文本读写快，而且不会有精度丢失。

### 文件定位函数

- `rewind(fp)` -- 把文件指针移回文件开头（rewind = 倒带）
- `fseek(fp, 偏移量, 起点)` -- 把文件指针移动到指定位置
  - 起点：`SEEK_SET`（文件头）、`SEEK_CUR`（当前位置）、`SEEK_END`（文件尾）
- `ftell(fp)` -- 返回当前文件指针的位置（离文件头多少字节）

```c
fseek(fp, 0, SEEK_END);     // 移到文件末尾
long size = ftell(fp);       // 获取文件大小（字节数）
rewind(fp);                   // 移回开头
```

### C 和 C++ 到底有什么区别？

一句话总结：**C++ 是 C 的超集，在 C 的基础上加了面向对象、泛型编程、STL 标准库等特性。** 所有合法的 C 代码基本都能在 C++ 里跑，但 C++ 多了很多东西。

| 对比项  | C 语言                       | C++                              |
|---|---|---|
| 编程思想 | **面向过程**：关注"怎么一步步做"        | 面向对象 + 面向过程兼备：关注"谁来做"            |
| 结构体  | struct 只能放数据，不能放函数         | struct 可以放数据 + 函数（和 class 几乎一样）  |
| 输入输出 | `scanf` / `printf`         | `cin` / `cout`（更方便、更安全）          |
| 字符串  | 用 `char[]` + `string.h` 函数 | 有 `string` 类，可以直接 `+` 拼接、`==` 比较 |
| 内存分配 | `malloc` / `free`          | `new` / `delete`（会自动调用构造/析构函数）   |
| 函数   | 同名函数不能有多个                  | 支持**函数重载**（同名但参数不同）              |
| 错误检查 | 编译期不严格检查类型匹配               | 编译期更严格，类型检查更安全                   |
| 标准库  | 很少，几乎什么都要自己写               | STL 提供大量现成容器和算法                  |

**学习建议：** 先学好 C 语言基础（前十章），再学 C++ 新增的这些特性，会发现很多 C 里很麻烦的事在 C++ 里变得很简单。

### 1. 命名空间 namespace

**问题：** 在一个大项目里，你写了一个叫 `print` 的函数，同事也写了一个叫 `print` 的函数，名字冲突了怎么办？
**C 的做法：** 没有好办法，只能自己注意命名不要重复，或者加前缀（比如 `my_print`、`utils_print`）。
**C++ 的做法：** 用 namespace 把代码分组。

```cpp
#include <iostream>
using namespace std;    // 使用标准命名空间（这样可以直接写 cout，不用写 std::cout）

namespace MyLib {
    void print() {
        cout << "MyLib 的 print" << endl;
    }
}

namespace YourLib {
    void print() {
        cout << "YourLib 的 print" << endl;
    }
}

int main() {
    MyLib::print();     // 调用 MyLib 里的 print
    YourLib::print();   // 调用 YourLib 里的 print
    return 0;
}
```

**`::` 叫"作用域解析运算符"**，告诉编译器"去哪个命名空间里找这个东西"。
`using namespace std;` 的意思是"以后用标准库的东西不用写 `std::` 前缀了"。写小程序可以这么用，大项目不建议（容易冲突）。
---

### 2. 引用 &

**引用 = 给变量起一个别名。** 就像你的真名叫陈智祥，但朋友也叫你小陈，"小陈"和"陈智祥"是同一个人。

```cpp
int a = 10;
int &b = a;    // b 是 a 的别名，b 和 a 指向同一块内存

b = 20;        // 通过 b 修改，a 也变成 20
cout << a;     // 输出 20
```

**和 C 语言指针的区别：**

| 指针（C） | 引用（C++）             |                  |
|---|---|---|
| 声明    | `int *p = &a;`      | `int &b = a;`    |
| 使用    | `*p` 解引用才能访问值       | 直接用 `b`，不用解引用    |
| 能否为空  | `int *p = NULL;` 可以 | 引用必须在声明时就绑定，不能为空 |
| 能否改指向 | `p = &b;` 可以改       | 引用一旦绑定就不能改       |

**引用最大的用处：函数参数传递。**
C 语言里要交换两个数必须传指针：

```c
// C 语言写法
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
swap(&x, &y);  // 传地址
```

C++ 里用引用，写法和调用都更自然：

```cpp
// C++ 写法
void swap(int &a, int &b) {  // a, b 是外面实参的别名
    int temp = a;
    a = b;
    b = temp;
}
swap(x, y);  // 直接传变量，不用加 &
```

---

### 3. 函数重载

**C 语言不允许同名函数。** 如果你要写一个 `max` 求两个 int 的最大值，再写一个 `max` 求两个 float 的最大值，C 语言会报错，只能叫 `max_int` 和 `max_float`。
**C++ 允许同名函数，只要参数列表不同就行：**

```cpp
int max(int a, int b) {
    return (a > b) ? a : b;
}

float max(float a, float b) {
    return (a > b) ? a : b;
}

int max(int a, int b, int c) {  // 参数个数不同也行
    return max(max(a, b), c);
}

int main() {
    cout << max(3, 5) << endl;       // 调用两个参数的 int 版本 → 5
    cout << max(1.5f, 2.5f) << endl;  // 调用 float 版本 → 2.5
    cout << max(1, 2, 3) << endl;     // 调用三个参数的版本 → 3
    return 0;
}
```

编译器根据你调用时传的参数类型和个数，**自动选择**对应的函数。
**注意：** 只有返回值不同、参数完全相同的两个函数**不能**构成重载（编译器无法区分）。

### 4. const

`const` = 这个值一旦赋值就不能改（"只读"）。

```cpp
const int PI = 3;     // PI 不能再改了
// PI = 4;             // 编译报错！

const int &ref = a;   // const 引用：可以通过它读 a，但不能通过它改 a
```

**和 C 的 `#define` 比：**
- `#define PI 3.14` 是简单的文本替换，编译器看不到 PI 这个名字
- `const double PI = 3.14` 是真正的变量，有类型检查，调试时能看到名字
C++ 里优先用 `const`，更安全更清晰。

### 5. new 和 delete（C++ 版的 malloc/free）

```cpp
// C 语言写法
int *p = (int *)malloc(5 * sizeof(int));
*p = 10;
free(p);

// C++ 写法
int *p = new int(10);              // 申请一个 int，值为 10
int *arr = new int[5];             // 申请 5 个 int 的数组
arr[0] = 10;

delete p;          // 释放单个
delete[] arr;      // 释放数组（注意加 []）
```

**new/delete 和 malloc/free 的区别：**

| malloc/free（C） | new/delete（C++）     |                           |
|---|---|---|
| 类型安全           | 返回 `void*`，需要手动强制转换 | 自动返回正确类型的指针               |
| 初始化            | 申请的内存是垃圾值           | `new int(10)` 可以直接初始化为 10 |
| 构造/析构          | 不会调用构造函数和析构函数       | 自动调用（对 class 对象很重要）       |
| 失败处理           | 返回 `NULL`           | 抛出异常                      |

**规则：** C++ 里用了 `new` 就必须用 `delete`，用了 `new[]` 就必须用 `delete[]`，不能混用。
---

### 6. string 字符串类

**C 语言的字符串（char 数组）问题：**
- 长度固定，容易越界
- 操作麻烦（`strcpy`、`strcat` 容易出错）
- 不能直接用 `+` 拼接，不能直接用 `==` 比较
**C++ 的 string 类解决了这些问题：**

```cpp
#include <string>
using namespace std;

string s1 = "Hello";
string s2 = " World";

// 拼接（C 里要用 strcat）
string s3 = s1 + s2;       // s3 = "Hello World"

// 比较（C 里要用 strcmp）
if (s1 == "Hello") { ... }  // 直接用 ==！
if (s1 != s2) { ... }

// 获取长度
int len = s1.length();      // 或 s1.size()

// 访问字符
char ch = s1[0];            // ch = 'H'

// 查找子串
int pos = s1.find("ll");    // 返回 2（从 0 开始数，"ll" 在位置 2）

// 截取子串
string sub = s1.substr(0, 3); // 从位置 0 开始取 3 个字符 → "Hel"
```

**总结：** 能用 `string` 就用 `string`，比 C 的 `char[]` + `string.h` 方便太多。

### 7. cin 和 cout（C++ 的输入输出）

```cpp
#include <iostream>
using namespace std;

int a;
float b;
string s;

cin >> a;           // 从键盘读一个整数（不需要 &！）
cin >> a >> b;      // 连续读多个
cout << a << endl;  // 输出 a 并换行（endl = 换行 + 刷新缓冲区）
cout << "a = " << a << ", b = " << b << endl;  // 链式输出
```

**和 C 语言的 printf/scanf 对比：**

| C（printf/scanf） | C++（cout/cin）     |              |
|---|---|---|
| 格式控制            | 用 `%d`、`%f` 等格式符  | 自动识别类型，不用格式符 |
| 取地址             | scanf 需要 `&`      | cin 不需要 `&`  |
| 安全性             | 格式符和变量类型不匹配会出 bug | 类型安全，编译器会检查  |
| 速度              | 较快                | 稍慢（但日常使用无感）  |

**OJ 刷题小提示：** 有些 OJ 系统用 `cin/cout` 可能会超时，可以加上这行关闭同步来加速：

```cpp
ios::sync_with_stdio(false);
cin.tie(nullptr);
```

### 8. 面向对象编程（OOP）

这是 C++ 和 C 最本质的区别。C 语言是"面向过程"的，关注步骤；C++ 是"面向对象"的，关注"谁来做"。
**生活类比：**
- **面向过程（C）**：你自己做一顿饭 -- 洗菜、切菜、炒菜、装盘（关注每一步怎么做）
- **面向对象（C++）**：你去饭店，告诉厨师"我要一份宫保鸡丁"。厨师（对象）内部怎么做的你不用管，他给你成品（关注"谁"来做）

#### 类和对象

**类 = 设计图纸，对象 = 按图纸造出来的实物。**

```cpp
class Student {
public:                    // public = 外面可以访问
    string name;
    int age;
    float score;

    void printInfo() {     // 类里面可以放函数！
        cout << name << " " << age << " " << score << endl;
    }

    float getGrade() {      // 方法（函数）
        if (score >= 90) return 'A';
        if (score >= 80) return 'B';
        if (score >= 60) return 'C';
        return 'D';
    }
};

int main() {
    Student s1;                // 按照类创建一个对象（实例化）
    s1.name = "Alice";         // 用 . 访问成员
    s1.age = 20;
    s1.score = 95;
    s1.printInfo();            // 调用对象的方法
    cout << s1.getGrade() << endl;  // 输出 A
    return 0;
}
```

**和 C 的 struct 对比：** C 的 struct 只能放数据不能放函数，C++ 的 class 可以放数据+函数。C++ 的 struct 也能放函数（和 class 几乎一样，唯一区别是默认访问权限：class 默认 private，struct 默认 public）。

#### 访问控制（封装）

```cpp
class BankAccount {
private:              // private = 只有类内部能访问，外面不能直接改
    string owner;
    double balance;

public:               // public = 外面可以访问
    BankAccount(string name, double money) {  // 构造函数
        owner = name;
        balance = money;
    }

    void deposit(double amount) {   // 存钱
        if (amount > 0)
            balance += amount;
    }

    void withdraw(double amount) {  // 取钱
        if (amount > 0 && amount <= balance)
            balance -= amount;
    }

    double getBalance() {           // 查余额
        return balance;
    }
};
```

**为什么要封装？** 保护数据不被乱改。余额 `balance` 是 private 的，外面不能直接 `account.balance = -100`，只能通过 `deposit()` 和 `withdraw()` 来操作，这样就能在里面加验证逻辑。

#### 构造函数和析构函数

**构造函数 = 创建对象时自动调用的"初始化函数"。**

```cpp
class Student {
private:
    string name;
    int age;
public:
    // 构造函数：函数名和类名相同，没有返回值
    Student(string n, int a) {
        name = n;
        age = a;
    }

    // 析构函数：函数名是 ~类名，没有返回值，没有参数
    // 对象被销毁时自动调用（通常用来释放动态内存）
    ~Student() {
        cout << name << " 被销毁了" << endl;
    }
};
```

```cpp
Student s1("Alice", 20);   // 调用构造函数，初始化
// s1 离开作用域时，自动调用析构函数
```

**构造函数的特殊之处：**
- 函数名和类名一样
- 没有返回值类型（连 `void` 都不写）
- 创建对象时自动调用，只调一次
- 可以有多个（重载），比如无参构造、有参构造、拷贝构造

#### 拷贝构造函数

用一个已有对象创建新对象时调用：

```cpp
Student s1("Alice", 20);
Student s2 = s1;    // 调用拷贝构造函数，把 s1 的数据复制给 s2
```

如果不自己写，编译器会自动生成一个"浅拷贝"版本。但如果类里有指针成员，浅拷贝会导致两个对象指向同一块内存，**非常危险**，这时候必须自己写拷贝构造函数。

#### 继承

**继承 = 子类复用父类的代码。**

```cpp
// 父类（基类）
class Animal {
public:
    string name;
    void eat() {
        cout << name << " 在吃饭" << endl;
    }
};

// 子类（派生类）继承父类
class Dog : public Animal {     // Dog 继承了 Animal
public:
    void bark() {
        cout << name << " 在汪汪叫" << endl;
    }
};

int main() {
    Dog d;
    d.name = "旺财";       // 从父类继承来的 name
    d.eat();                // 从父类继承来的 eat()
    d.bark();               // 自己的方法
    return 0;
}
```

**为什么要继承？** 避免重复代码。`Cat`、`Bird`、`Fish` 都有 `name` 和 `eat()`，不用每个都写一遍，写一次 `Animal` 父类，其他类继承它就行。

#### 多态和虚函数

**多态 = 同一个方法，不同对象调用有不同的行为。**

```cpp
class Animal {
public:
    virtual void speak() {         // virtual = 虚函数
        cout << "动物叫" << endl;
    }
};

class Dog : public Animal {
public:
    void speak() {                 // 子类重写了 speak()
        cout << "汪汪！" << endl;
    }
};

class Cat : public Animal {
public:
    void speak() {
        cout << "喵喵！" << endl;
    }
};

int main() {
    Animal *a1 = new Dog();    // 父类指针指向子类对象
    Animal *a2 = new Cat();

    a1->speak();    // 输出"汪汪！"（不是"动物叫"）
    a2->speak();    // 输出"喵喵！"（不是"动物叫"）
    // 因为 speak 是虚函数，实际调用的是子类的版本

    delete a1;
    delete a2;
    return 0;
}
```

**如果去掉 `virtual`：** `a1->speak()` 会输出"动物叫"，因为编译器根据指针类型（Animal*）决定调用哪个版本，而不是根据实际对象类型。
**纯虚函数和抽象类：**

```cpp
class Shape {                    // 抽象类
public:
    virtual double area() = 0;   // 纯虚函数（= 0 表示"没有实现"）
    // 含有纯虚函数的类不能直接创建对象
};

class Circle : public Shape {
    double radius;
public:
    Circle(double r) : radius(r) {}
    double area() { return 3.14159 * radius * radius; }  // 必须实现
};

class Rectangle : public Shape {
    double w, h;
public:
    Rectangle(double w, double h) : w(w), h(h) {}
    double area() { return w * h; }
};
```

**纯虚函数的意义：** 强制子类必须实现某个方法。就像老板规定"所有员工都必须有工作能力"，具体怎么工作各人自己实现，但不能不实现。

### 9. STL 标准模板库

**STL = Standard Template Library，C++ 自带的一堆现成的数据结构和算法。** 这是 C++ 相比 C 语言最大的优势之一。C 语言里你要自己写链表、排序、查找，C++ 里直接用现成的。

#### vector -- 动态数组

**C 的数组大小固定，C++ 的 vector 可以自动扩容。**

```cpp
#include <vector>
using namespace std;

vector<int> v;              // 创建一个空的 int 动态数组

v.push_back(10);            // 末尾添加元素
v.push_back(20);
v.push_back(30);

cout << v[0] << endl;       // 10（和数组一样用下标访问）
cout << v.size() << endl;    // 3（元素个数）
v.pop_back();               // 删除末尾元素，v 变成 {10, 20}

// 用迭代器遍历
for (vector<int>::iterator it = v.begin(); it != v.end(); it++) {
    cout << *it << " ";      // *it 解引用，获取元素值
}

// C++11 更简洁的遍历方式
for (int x : v) {           // 范围 for 循环
    cout << x << " ";
}
```

**和 C 数组对比：**
- 大小不用预先确定，`push_back` 自动扩容
- 有 `size()` 方法知道元素个数
- 有 `push_back`、`pop_back`、`insert`、`erase` 等操作
- 会自动管理内存，不用担心越界

#### map -- 键值对

**map 就像字典：通过"键"快速查到"值"。**

```cpp
#include <map>

map<string, int> m;         // 键是 string，值是 int

m["Alice"] = 95;            // 添加键值对
m["Bob"] = 88;
m["Charlie"] = 76;

cout << m["Alice"] << endl;  // 95，通过键查找值

// 遍历
for (auto &p : m) {          // auto 让编译器自动推断类型
    cout << p.first << " " << p.second << endl;  // first=键, second=值
}

// 检查某个键是否存在
if (m.find("David") != m.end()) {
    cout << "找到了" << endl;
} else {
    cout << "没找到" << endl;
}
```

**常见用途：** 统计词频（统计每个单词出现了多少次）、电话簿（名字→号码）、配置映射等。

#### set -- 不重复集合

**set 里的元素自动排序，而且不会重复。**

```cpp
#include <set>

set<int> s;
s.insert(10);
s.insert(30);
s.insert(20);
s.insert(10);     // 重复插入，不会生效，set 里只有一个 10

// 遍历（自动从小到大排序）
for (int x : s) {
    cout << x << " ";   // 输出：10 20 30
}

cout << s.count(10) << endl;  // 1（存在）
cout << s.count(40) << endl;  // 0（不存在）
```

**常见用途：** 去重、判断某个元素是否存在、求交集/并集。

#### stack 和 queue

**stack（栈）= 后进先出（LIFO）：** 像叠盘子，最后放上去的先拿下来

```cpp
#include <stack>

stack<int> stk;
stk.push(10);       // 放入
stk.push(20);
cout << stk.top();  // 20（栈顶元素）
stk.pop();          // 弹出栈顶
cout << stk.top();  // 10
```

**queue（队列）= 先进先出（FIFO）：** 像排队买饭，先来的先服务

```cpp
#include <queue>

queue<int> q;
q.push(10);        // 入队
q.push(20);
cout << q.front(); // 10（队首元素）
q.pop();           // 出队
cout << q.front(); // 20
```

#### sort -- 排序

```cpp
#include <algorithm>
#include <vector>

vector<int> v = {5, 3, 1, 4, 2};
sort(v.begin(), v.end());            // 从小到大排序 → {1, 2, 3, 4, 5}

// 从大到小排序
sort(v.begin(), v.end(), greater<int>());

// 自定义排序规则
sort(v.begin(), v.end(), [](int a, int b) {
    return a > b;    // 降序（lambda 表达式）
});
```

C 语言里要自己写冒泡排序/快排，C++ 里一行 `sort()` 搞定。

### 10. 模板与泛型编程

**模板 = 写一个"通用版本"，让它支持多种数据类型。**
比如你想写一个求最大值的函数，既支持 int 又支持 float 又支持 double，不用写三个函数重载，写一个模板就行：

```cpp
// 函数模板
template <typename T>
T myMax(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    cout << myMax(3, 5) << endl;         // 自动推导 T = int，输出 5
    cout << myMax(1.5, 2.5) << endl;     // 自动推导 T = double，输出 2.5
    cout << myMax('a', 'z') << endl;     // 自动推导 T = char，输出 z
    return 0;
}
```

编译器根据你调用时的参数类型，**自动生成**对应版本的函数。你只写了一份代码，实际上编译器帮你生成了多份。
**类模板：**

```cpp
template <typename T>
class Stack {
private:
    T data[100];
    int top;
public:
    Stack() : top(-1) {}
    void push(T value) { data[++top] = value; }
    T pop() { return data[top--]; }
};
```

这样 `Stack<int>` 就是 int 栈，`Stack<string>` 就是 string 栈，一套代码搞定所有类型。
