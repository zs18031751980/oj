# 并发与多线程库详解

## 一、C++11 标准多线程

C++11 起标准库自带线程支持，大部分场景无需第三方库。

### 1.1 std::thread

```cpp
#include <thread>
#include <iostream>

// 基本使用
void work(int n) {
    std::cout << "线程 " << n << " 执行\n";
}

std::thread t1(work, 1);       // 创建线程
std::thread t2([]{              // Lambda
    std::cout << "lambda 线程\n";
});

t1.join();                      // 等待线程结束
t2.detach();                    // 分离线程（后台运行，不可再 join）

std::cout << "主线程继续\n";
```

### 1.2 std::mutex（互斥锁）

```cpp
#include <mutex>

std::mutex mtx;
int counter = 0;

void increment() {
    for (int i = 0; i < 100000; i++) {
        // 方式1：lock_guard（RAII，自动解锁）
        std::lock_guard<std::mutex> lock(mtx);
        counter++;
    }
}

void safe_increment() {
    // 方式2：unique_lock（更灵活，可手动 lock/unlock）
    std::unique_lock<std::mutex> lock(mtx);
    counter++;
    lock.unlock();
    // 做些其他事
    lock.lock();
    counter++;
}
```

### 1.3 std::shared_mutex（读写锁，C++17）

```cpp
#include <shared_mutex>

std::shared_mutex rw_lock;
std::map<int, int> data;

void reader() {
    std::shared_lock<std::shared_mutex> lock(rw_lock);  // 共享锁
    // 多个 reader 可以同时读
    auto val = data[0];
}

void writer() {
    std::unique_lock<std::shared_mutex> lock(rw_lock);  // 独占锁
    data[0] = 42;
}
```

### 1.4 std::condition_variable（条件变量）

```cpp
#include <condition_variable>

std::mutex cv_mtx;
std::condition_variable cv;
bool ready = false;
std::queue<int> task_queue;

void producer() {
    for (int i = 0; i < 10; i++) {
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
        {
            std::lock_guard<std::mutex> lock(cv_mtx);
            task_queue.push(i);
            ready = true;
        }
        cv.notify_one();  // 唤醒一个等待线程
    }
}

void consumer() {
    for (int i = 0; i < 10; i++) {
        std::unique_lock<std::mutex> lock(cv_mtx);
        cv.wait(lock, []{ return ready; });  // 等待条件
        int task = task_queue.front();
        task_queue.pop();
        ready = false;
        std::cout << "消费: " << task << "\n";
    }
}
```

### 1.5 std::atomic（原子操作）

```cpp
#include <atomic>

std::atomic<int> counter{0};

void add() {
    for (int i = 0; i < 100000; i++)
        counter.fetch_add(1);  // 线程安全的自增（无锁）
}

// 原子标志
std::atomic_flag flag = ATOMIC_FLAG_INIT;
flag.test_and_set();   // 设为 true，返回旧值
flag.clear();          // 设为 false
```

### 1.6 std::future / std::async（异步任务）

```cpp
#include <future>

// 异步执行函数，返回 future
std::future<int> result = std::async(std::launch::async, []{
    std::this_thread::sleep_for(std::chrono::seconds(1));
    return 42;
});

// 做点其他事
std::cout << "等待结果...\n";
int value = result.get();  // 阻塞等待结果
std::cout << "结果: " << value << "\n";

// packaged_task
std::packaged_task<int(int,int)> task([](int a, int b){ return a + b; });
std::future<int> fut = task.get_future();
std::thread t(std::move(task), 3, 4);
t.join();
std::cout << fut.get() << "\n";

// promise
std::promise<int> prom;
std::future<int> fut2 = prom.get_future();
std::thread t2([&prom]{ prom.set_value(99); });
t2.join();
std::cout << fut2.get() << "\n";
```

## 二、Intel TBB（Threading Building Blocks）

### 概述
Intel 出品的高级并行算法库，将循环/任务自动分配到多核。

### 安装
vcpkg: `vcpkg install tbb`

### 并行 for 循环

```cpp
#include <tbb/parallel_for.h>
#include <tbb/blocked_range.h>

// 最简单的并行 for
tbb::parallel_for(0, n, [&](int i) {
    result[i] = compute(i);  // 自动并行执行
});

// 带范围的并行 for（减少任务开销）
tbb::parallel_for(tbb::blocked_range<int>(0, n),
    [&](const tbb::blocked_range<int>& r) {
        for (int i = r.begin(); i < r.end(); ++i)
            result[i] = compute(i);
    });
```

### 并行 reduce

```cpp
#include <tbb/parallel_reduce.h>

// 并行求和
double sum = tbb::parallel_reduce(
    tbb::blocked_range<int>(0, n), 0.0,
    [&](const tbb::blocked_range<int>& r, double init) {
        for (int i = r.begin(); i < r.end(); ++i)
            init += data[i];
        return init;
    },
    std::plus<double>()  // 合并各块结果
);
```

### 并行排序

```cpp
#include <tbb/parallel_sort.h>

std::vector<int> v = {9,3,5,1,8,2,7,4,6};
tbb::parallel_sort(v.begin(), v.end());  // 并行快速排序
```

### 任务组

```cpp
#include <tbb/task_group.h>

tbb::task_group tg;
tg.run([&]{ task1(); });
tg.run([&]{ task2(); });
tg.run([&]{ task3(); });
tg.wait();  // 等待所有任务完成
```

### 并行流水线

```cpp
#include <tbb/pipeline.h>
// 适合生产者-消费者模式
```

## 三、Abseil（Google 的 C++ 通用库）

### 概述
Google 开源的 C++ 基础库，包含线程池、同步、容器增强等。

### 安装
vcpkg: `vcpkg install abseil`

### 常用组件

```cpp
// 线程池（Notification + Mutex）
#include "absl/synchronization/notification.h"
#include "absl/synchronization/mutex.h"

absl::Mutex mtx;
absl::Notification done;

// 简单的线程间同步
std::thread t([&]{
    // 工作
    done.Notify();  // 通知完成
});
done.WaitForNotification();  // 等通知

// 字符串工具（比 std 更强）
#include "absl/strings/str_join.h"
#include "absl/strings/str_split.h"
#include "absl/strings/str_replace.h"

std::vector<std::string> parts = absl::StrSplit("a,b,c", ",");
std::string joined = absl::StrJoin(parts, "-");  // "a-b-c"
```

### TBB vs 标准库 vs Abseil 对比

| 功能 | C++ 标准 | TBB | Abseil |
|------|---------|-----|--------|
| 基本线程 | std::thread | — | — |
| 互斥锁 | std::mutex | tbb::mutex | absl::Mutex |
| 读写锁 | std::shared_mutex (C++17) | tbb::spin_rw_mutex | — |
| 原子操作 | std::atomic | tbb::atomic | — |
| 并行 for | — | tbb::parallel_for | — |
| 并行 reduce | — | tbb::parallel_reduce | — |
| 并行排序 | — | tbb::parallel_sort | — |
| 线程池 | std::async | tbb::task_group | absl::Notification |
| 任务调度 | — | tbb::task_scheduler_attach | — |

**选型建议：**
- 简单并行 → `std::async` + `std::thread`
- 高性能数值计算/循环 → **TBB**（`parallel_for` / `parallel_reduce`）
- Google 风格项目 → **Abseil**

### 编译示例

```bash
# TBB
g++ -std=c++17 -O2 main.cpp -ltbb -o app

# 标准库（无需链接）
g++ -std=c++17 -O2 -pthread main.cpp -o app
```
