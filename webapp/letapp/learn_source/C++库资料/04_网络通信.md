# 网络通信库详解

## 一、Boost.Asio — 跨平台异步网络

### 概述
Boost.Asio 是 C++ 最常用的异步网络库。支持 TCP/UDP、串口、定时器、信号处理。

### 核心组件

| 组件 | 说明 |
|------|------|
| `asio::io_context` | 事件循环（核心调度器） |
| `asio::ip::tcp::socket` | TCP socket |
| `asio::ip::tcp::acceptor` | TCP 服务端监听 |
| `asio::ip::udp::socket` | UDP socket |
| `asio::steady_timer` | 定时器 |
| `asio::buffer()` | 数据缓冲区包装 |

### 基础 TCP 客户端

```cpp
#include <boost/asio.hpp>
#include <iostream>
namespace asio = boost::asio;
using asio::ip::tcp;

int main() {
    asio::io_context io;
    tcp::socket sock(io);
    tcp::resolver resolver(io);

    // 域名解析 + 连接
    asio::connect(sock, resolver.resolve("example.com", "80"));

    // 发送 HTTP 请求
    std::string req = "GET / HTTP/1.1\r\nHost: example.com\r\nConnection: close\r\n\r\n";
    asio::write(sock, asio::buffer(req));

    // 接收响应
    asio::streambuf response;
    asio::read_until(sock, response, "\r\n\r\n");
    std::cout << &response;

    return 0;
}
```

### 基础 TCP 服务端

```cpp
asio::io_context io;
tcp::acceptor acceptor(io, tcp::endpoint(tcp::v4(), 8080));

while (true) {
    tcp::socket sock(io);
    acceptor.accept(sock);  // 阻塞等待连接

    std::string msg = "hello from server\n";
    asio::write(sock, asio::buffer(msg));
}
```

### 异步服务端

```cpp
class Server {
public:
    Server(asio::io_context& io, short port)
        : acceptor_(io, tcp::endpoint(tcp::v4(), port)) {
        do_accept();
    }

private:
    void do_accept() {
        auto sock = std::make_shared<tcp::socket>(acceptor_.get_executor());
        acceptor_.async_accept(*sock,
            [this, sock](boost::system::error_code ec) {
                if (!ec) do_read(sock);
                do_accept();  // 继续监听下一个
            });
    }

    void do_read(std::shared_ptr<tcp::socket> sock) {
        auto buf = std::make_shared<asio::streambuf>();
        asio::async_read_until(*sock, *buf, "\n",
            [this, sock, buf](boost::system::error_code ec, size_t len) {
                if (!ec) {
                    std::cout << &(*buf);
                    do_read(sock);
                }
            });
    }

    tcp::acceptor acceptor_;
};
```

### 定时器

```cpp
asio::io_context io;
asio::steady_timer timer(io, std::chrono::seconds(5));
timer.wait();  // 阻塞等5秒

// 异步定时器
timer.expires_after(std::chrono::seconds(5));
timer.async_wait([](boost::system::error_code ec) {
    std::cout << "timeout!\n";
});
io.run();  // 必须 run 才能触发回调
```

### UDP

```cpp
asio::io_context io;
asio::ip::udp::socket sock(io, asio::ip::udp::endpoint(asio::ip::udp::v4(), 8888));
char buf[1024];
asio::ip::udp::endpoint sender;
size_t len = sock.receive_from(asio::buffer(buf), sender);
sock.send_to(asio::buffer(buf, len), sender);
```

### 编译

```bash
# 需要链接 -lboost_system（Windows 上还需 -lws2_32）
g++ main.cpp -lboost_system -lws2_32 -o server
# 仅头文件模式（无需编译 lib）
#define BOOST_ASIO_HEADER_ONLY
#include <boost/asio.hpp>
```

## 二、libcurl — HTTP/HTTPS 客户端（对标 Python requests）

### 概述
libcurl 是最广泛使用的 URL 传输库，支持 HTTP、FTP、SMTP 等协议。

### 安装
- vcpkg: `vcpkg install curl`
- 或下载预编译二进制

### 基础 GET 请求

```cpp
#include <curl/curl.h>
#include <string>

// 回调函数：将服务器返回的数据写入 string
size_t write_callback(void* contents, size_t size, size_t nmemb, void* userp) {
    ((std::string*)userp)->append((char*)contents, size * nmemb);
    return size * nmemb;
}

int main() {
    CURL* curl = curl_easy_init();
    if (!curl) return -1;

    std::string response;
    curl_easy_setopt(curl, CURLOPT_URL, "https://api.example.com/data");
    curl_easy_setopt(curl, CURLOPT_WRITEFUNCTION, write_callback);
    curl_easy_setopt(curl, CURLOPT_WRITEDATA, &response);
    curl_easy_setopt(curl, CURLOPT_TIMEOUT, 10L);

    CURLcode res = curl_easy_perform(curl);
    if (res == CURLE_OK) {
        long http_code;
        curl_easy_getinfo(curl, CURLINFO_RESPONSE_CODE, &http_code);
        std::cout << "HTTP " << http_code << "\n" << response;
    }

    curl_easy_cleanup(curl);
    return 0;
}
```

### POST JSON

```cpp
curl_easy_setopt(curl, CURLOPT_URL, "https://api.example.com/post");
curl_easy_setopt(curl, CURLOPT_POSTFIELDS, R"({"key":"value"})");

// 设置请求头
struct curl_slist* headers = nullptr;
headers = curl_slist_append(headers, "Content-Type: application/json");
curl_easy_setopt(curl, CURLOPT_HTTPHEADER, headers);

// 执行 + 清理
curl_easy_perform(curl);
curl_slist_free_all(headers);
```

### 常见选项

| 选项 | 说明 |
|------|------|
| `CURLOPT_URL` | URL |
| `CURLOPT_TIMEOUT` | 超时（秒） |
| `CURLOPT_FOLLOWLOCATION` | 跟随重定向 |
| `CURLOPT_SSL_VERIFYPEER` | 是否验证 SSL 证书（0=跳过） |
| `CURLOPT_USERAGENT` | User-Agent |
| `CURLOPT_HTTPHEADER` | 自定义请求头 |
| `CURLOPT_POSTFIELDS` | POST 数据 |
| `CURLOPT_WRITEFUNCTION` | 写回调 |
| `CURLOPT_READDATA` | 读回调（上传文件） |
| `CURLOPT_VERBOSE` | 调试日志 |

### 编译

```bash
g++ main.cpp -lcurl -o app
```

## 三、WebSocket++ — WebSocket 客户端/服务端

### 概述
WebSocket 协议的全双工通信库，头文件库，基于 Boost.Asio。

### 服务端
```cpp
#include <websocketpp/config/asio_no_tls.hpp>
#include <websocketpp/server.hpp>
typedef websocketpp::server<websocketpp::config::asio> server;

void on_message(server* s, websocketpp::connection_hdl hdl, server::message_ptr msg) {
    s->send(hdl, "echo: " + msg->get_payload(), msg->get_opcode());
}

int main() {
    server s;
    s.init_asio();
    s.set_message_handler(bind(&on_message, &s, placeholders::_1, placeholders::_2));
    s.listen(9002);
    s.start_accept();
    s.run();
}
```

### 客户端
```cpp
#include <websocketpp/config/asio_no_tls_client.hpp>
#include <websocketpp/client.hpp>
typedef websocketpp::client<websocketpp::config::asio_client> client;

int main() {
    client c;
    c.init_asio();

    websocketpp::lib::error_code ec;
    auto conn = c.get_connection("ws://localhost:9002", ec);
    if (ec) { std::cerr << ec.message(); return -1; }

    conn->set_message_handler([](websocketpp::connection_hdl, client::message_ptr msg) {
        std::cout << "收到: " << msg->get_payload() << "\n";
    });

    c.connect(conn);
    c.run();
}
```

### 编译
```bash
# 需要 Boost.Asio
g++ -std=c++17 -O2 main.cpp -lboost_system -lws2_32 -lpthread -o ws
```

## 四、POCO — 一站式网络 + 工具库

### 概述
POCO（POrtable COmponents）是一个包含网络、HTTP、XML、JSON、数据库、日志等功能的综合 C++ 库，定位类似 Java 的 JDK。

### 安装
vcpkg: `vcpkg install poco`

### HTTP 客户端
```cpp
#include <Poco/Net/HTTPClientSession.h>
#include <Poco/Net/HTTPRequest.h>
#include <Poco/Net/HTTPResponse.h>
#include <Poco/StreamCopier.h>
#include <iostream>
#include <sstream>

using namespace Poco::Net;

int main() {
    HTTPClientSession session("api.example.com");
    HTTPRequest req(HTTPRequest::HTTP_GET, "/data");
    session.sendRequest(req);

    HTTPResponse res;
    std::istream& body = session.receiveResponse(res);
    std::cout << "Status: " << res.getStatus() << "\n";

    std::string body_str;
    Poco::StreamCopier::copyToString(body, body_str);
    std::cout << body_str;

    return 0;
}
```

### HTTP 服务端
```cpp
#include <Poco/Net/HTTPServer.h>
#include <Poco/Net/HTTPRequestHandler.h>
#include <Poco/Net/HTTPRequestHandlerFactory.h>
#include <Poco/Net/HTTPServerParams.h>
#include <Poco/Net/ServerSocket.h>

class MyHandler : public HTTPRequestHandler {
    void handleRequest(HTTPServerRequest& req, HTTPServerResponse& res) override {
        res.setStatus(HTTPResponse::HTTP_OK);
        res.setContentType("text/plain");
        std::ostream& out = res.send();
        out << "Hello from POCO!";
    }
};

int main() {
    ServerSocket svs(8080);
    HTTPServer srv(new MyHandler, svs, new HTTPServerParams);
    srv.start();
    std::cin.get();  // 等待退出
    srv.stop();
}
```

### POCO 主要模块

| 模块 | 说明 |
|------|------|
| Foundation | 基础工具：字符串、日期、日志、线程、文件系统 |
| Net | 网络：Socket、HTTP、FTP、SMTP、DNS |
| XML | XML 解析（DOM/SAX） |
| JSON | JSON 解析与生成 |
| Data | 数据库接口（MySQL、SQLite、PostgreSQL） |
| Crypto | 加密、SSL |
| Zip | ZIP 压缩 |
| Util | 配置、命令行、定时器 |

### 编译
```bash
g++ main.cpp -lPocoFoundation -lPocoNet -o app
```

## 对比总结

| 库 | 适用场景 | 头文件？ |
|------|---------|---------|
| Boost.Asio | TCP/UDP 底层网络、异步 I/O | 否（可头文件模式） |
| libcurl | HTTP/HTTPS 请求、文件上传下载、爬虫 | 否 |
| WebSocket++ | WebSocket 实时通信 | 是（依赖 Asio） |
| POCO | 全栈网络应用（HTTP 服务端+客户端+数据库+日志） | 否 |
