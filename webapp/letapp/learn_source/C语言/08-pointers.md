**指针是 C 语言最重要也最难的概念。用简单的话说：指针就是"地址"。**

### 内存和地址

电脑内存可以想象成一排排的**小格子**，每个格子有：
- 一个**地址**（门牌号）
- 里面存的**数据**（住的人）

```
地址：  0x1000  0x1004  0x1008  0x100C  ...
数据：    10      20      30      40
名字：     a       b       c       d
```

当你写 `int a = 10;`，电脑就找一块空格子，把 10 放进去，然后记住了"格子 a 在地址 0x1000"。

### 什么是指针

**指针变量 = 专门用来存地址的变量。** 普通变量存数据，指针变量存地址。

```c
int a = 10;       // 普通变量 a，里面存的是数据 10
int *p = &a;      // 指针变量 p，里面存的是 a 的地址
```

```
普通变量 a：          指针变量 p：
+--------+         +----------+
|   10   |  ←----  | 0x1000  |  （p 里存的是 a 的地址）
+--------+         +----------+
 地址0x1000           地址0x2000
```

**两个关键符号：**
- `&a` -- **取地址**，获取变量 a 的门牌号（`&` = "address of"）
- `*p` -- **解引用**，通过指针 p 里存的地址，找到那个格子，取出里面的值（`*p` 等价于 `a`，值为 10）

```c
int a = 10;
int *p = &a;

printf("%d\n", *p);   // 10（通过 p 找到 a，取出 10）
*p = 20;              // 通过 p 找到 a，把值改成 20
printf("%d\n", a);    // 20（a 被改了）
```

### 指针有什么用？

**最大的用处：通过函数修改变量的值。**
前面学过，值传递时形参不影响实参。但如果传的是地址，就能通过地址直接修改外面的变量：

```c
// 错误的交换：值传递，交换无效
void swap_wrong(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
    // 交换的是形参 a、b，外面的实参完全不受影响
}

// 正确的交换：传指针（地址传递）
void swap(int *pa, int *pb) {
    int temp = *pa;   // temp = *pa，即 temp = 外面那个变量的值
    *pa = *pb;         // 把外面另一个变量的值给第一个
    *pb = temp;         // temp 给第二个
    // 通过地址直接修改了外面的变量！
}

int main() {
    int x = 3, y = 7;
    swap(&x, &y);      // 传的是 x 和 y 的地址
    printf("x=%d, y=%d\n", x, y);  // x=7, y=3，交换成功！
}
```

**类比：** 值传递就像你把一张照片给朋友，朋友在照片上画画，不影响你手上的原件。地址传递就像你把家里的地址给朋友，朋友直接去你家改了东西。

### 指针与数组

数组名就是首元素的地址，所以指针和数组天然有关：

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;    // p 指向 a[0]，等价于 p = &a[0]
```

```
数组 a：[10] [20] [30] [40] [50]
          ↑
          p（指向 a[0]）
```

指针加减法的含义：

```c
p + 1    // 不是地址 +1 字节，而是指向下一个元素！
*(p + 2) // 等价于 a[2]，值为 30
p[3]     // 指针也能用下标，等价于 *(p + 3)，值为 40
```

**`p + i` 实际移动了多少字节？** 取决于元素大小。`int` 占 4 字节，所以 `p + 1` 实际地址加了 4 字节（跳过一个 int 的大小）。

### 动态内存分配

前面的数组大小都是写死的（`int a[100]`）。如果运行时才知道需要多大呢？用 `malloc`（memory allocate 的缩写）：

```c
int n;
scanf("%d", &n);   // 用户输入需要多少个整数
int *p = (int *)malloc(n * sizeof(int));  // 动态申请内存
//            ↑
//    把申请到的内存转换成 int* 类型（指向 int 的指针）
```

```c
if (p == NULL) {       // malloc 失败会返回 NULL
    printf("内存不足！\n");
    return 1;
}

// 现在可以像数组一样使用 p[0] ~ p[n-1] 了
for (int i = 0; i < n; i++) {
    scanf("%d", &p[i]);
}

free(p);    // 用完必须释放！不释放就是"内存泄漏"
p = NULL;  // 释放后把指针置空，防止误用（野指针）
```

**malloc 和数组的区别：**

| 数组   | malloc     |                  |
|---|---|---|
| 大小   | 固定（写死在代码里） | 动态（运行时决定）        |
| 内存位置 | 栈（自动管理）    | 堆（手动管理）          |
| 释放   | 函数结束自动回收   | 必须 `free()` 手动释放 |
