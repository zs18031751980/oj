**函数 = 把一段代码"打包"，起个名字，以后想用就直接喊名字。**

### 为什么需要函数？

假设你写了一个"求最大值"的逻辑，在程序里 5 个不同的地方都要用。如果没有函数，你要复制粘贴 5 次同样的代码。如果逻辑要修改，就要改 5 处。
有了函数：把逻辑写在一个地方（定义函数），5 个地方只写 `max(a, b)` 调用它。逻辑改了，只改一处就行。**代码更简洁、更好维护。**

### 函数的定义和调用

```c
// 定义函数（造工具）
int add(int a, int b) {
    return a + b;
}
//  ↑     ↑ ↑    ↑
//  返回值  函数名  参数（原材料）
//  类型

int main() {
    int result = add(3, 5);  // 调用函数（使用工具）
    // add(3, 5) 就是把 3 和 5 交给 add 函数处理
    // 它会返回 3+5=8，存到 result 里
    printf("%d\n", result);   // 输出 8
}
```

**定义函数的四个部分：**
1. **返回值类型**：函数执行完返回什么类型的数据（`int`、`float`、`void`=不返回）
2. **函数名**：给函数起个有意义的名字（`add`、`max`、`sort`...）
3. **参数列表**：函数需要什么原材料（可以有 0 个、1 个或多个）
4. **函数体**：花括号里的具体逻辑

### 形参和实参（概念很重要）

```c
int add(int a, int b) {  // a, b 叫"形参"（形式参数）
    return a + b;          // 相当于占位符
}

int main() {
    int x = 3, y = 5;
    int r = add(x, y);     // x, y 叫"实参"（实际参数）
    // 调用时：x 的值(3) 复制给 a，y 的值(5) 复制给 b
}
```

**关键理解：** 实参的值**复制**给形参，形参和实参是两个独立的变量。形参在函数里怎么改，都不影响外面的实参。这叫**值传递**。

```c
void try_change(int x) {
    x = 999;  // 只改了形参 x，外面的实参完全不受影响
}

int main() {
    int a = 10;
    try_change(a);
    printf("%d\n", a);  // 输出 10（没变！）
}
```

### 函数声明（原型）

如果函数定义在调用之后，C 编译器会报错说"找不到这个函数"。解决方法：在前面**声明**一下。

```c
int add(int a, int b);  // 声明（注意末尾有分号，不写函数体）

int main() {
    int r = add(3, 5);  // 现在编译器知道有 add 这个函数了
}

int add(int a, int b) {  // 定义
    return a + b;
}
```

### 递归 -- 函数自己调用自己

**递归 = 函数内部调用自己。** 听起来很怪？其实生活中也有递归。
举个例子：你问第 5 个人"你排第几"，第 5 个人说"我不知道，你问第 4 个人"，第 4 个人说"你问第 3 个人"... 一直问到第 1 个人，他说"我排第 1"。然后答案一层层传回来：第 2 = 第 1 + 1 = 2，第 3 = 第 2 + 1 = 3... 第 5 = 5。
**递归的两个要素（缺一不可）：**
1. **递归关系**：大问题怎么拆成小问题（`n! = n × (n-1)!`）
2. **终止条件**：最小的那个问题能直接回答（`1! = 1`）

```c
int factorial(int n) {
    if (n <= 1) {
        return 1;          // 终止条件：1的阶乘 = 1
    }
    return n * factorial(n - 1);  // 递归：n! = n × (n-1)!
}

// factorial(3) 的执行过程：
// factorial(3) = 3 * factorial(2)
//               = 3 * (2 * factorial(1))
//               = 3 * (2 * 1)
//               = 6
```

### 变量的作用域和生存期

| 类型       | 在哪定义         | 能被谁访问    | 什么时候生、什么时候死      |
|---|---|---|---|
| **局部变量** | 函数内部         | 只有本函数能访问 | 函数被调用时诞生，函数结束时死亡 |
| **全局变量** | 函数外部（所有函数外面） | 所有函数都能访问 | 程序启动时诞生，程序结束时死亡  |

```c
int g = 100;           // 全局变量

void func() {
    int x = 5;         // 局部变量，只在 func 里能用
    g = 200;           // 可以访问和修改全局变量
}

int main() {
    int y = 10;        // 局部变量，只在 main 里能用
    // x 在这里访问不到！
}
```

**`static` 局部变量** -- 函数结束后不销毁，下次调用时还保留上次的值：

```c
void counter() {
    static int count = 0;  // 只在第一次调用时初始化为 0
    count++;
    printf("%d\n", count);
}

int main() {
    counter();  // 输出 1
    counter();  // 输出 2（count 保留了上次的值 1，加 1 变 2）
    counter();  // 输出 3
}
```
