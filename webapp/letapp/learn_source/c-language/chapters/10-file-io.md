### 文件的基本概念

- **文本文件**：存的是人类可读的文字（如 `.txt`、`.c`）
- **二进制文件**：存的是计算机内部的格式，人类直接看是乱码（如 `.exe`、`.jpg`）

### FILE 指针

C 语言用 `FILE *` 类型的指针来操作文件。可以理解为"文件句柄"，你通过它和文件打交道：

```c
FILE *fp;
```

### fopen -- 打开文件

```c
fp = fopen("data.txt", "r");
//   文件名       打开模式
```

**常用打开模式：**

| 模式     | 含义   | 文件不存在时 | 文件已存在时     |
|---|---|---|---|
| `"r"`  | 只读   | 报错     | 从头开始读      |
| `"w"`  | 只写   | 创建新文件  | **清空原内容！** |
| `"a"`  | 追加写  | 创建新文件  | 在末尾追加      |
| `"r+"` | 读+写  | 报错     | 从头开始       |
| `"w+"` | 读+写  | 创建新文件  | 清空原内容      |
| `"rb"` | 二进制读 | 报错     | 从头开始读      |
| `"wb"` | 二进制写 | 创建新文件  | 清空原内容      |

**每次用 fopen 都要检查是否成功：**

```c
FILE *fp = fopen("data.txt", "r");
if (fp == NULL) {
    printf("文件打开失败！\n");
    return 1;
}
```

### fclose -- 关闭文件

**用完必须关闭！** 不关闭文件可能导致数据丢失。

```c
fclose(fp);
```

### fprintf / fscanf -- 格式化读写

和 `printf` / `scanf` 几乎一样，只是多了个文件指针参数：

```c
// 写入文件
fprintf(fp, "Name: %s, Score: %d\n", "Alice", 95);

// 从文件读取
char name[20];
int score;
fscanf(fp, "%s %d", name, &score);
```

### fgetc / fputc -- 逐字符读写

```c
fputc('A', fp);          // 往文件写一个字符 'A'
int ch = fgetc(fp);      // 从文件读一个字符
// 读到文件末尾，fgetc 返回 EOF（End Of File，值为 -1）
```

### fgets / fputs -- 字符串读写

```c
fputs("Hello", fp);      // 写一个字符串到文件（不自动加换行）
char buf[100];
fgets(buf, 100, fp);      // 从文件读一行（最多 99 个字符）
// fgets 会把换行符 \n 也读进来，遇到换行或读完 99 字符就停
```

### fwrite / fread -- 二进制读写

直接把内存里的数据按字节写入文件：

```c
struct Student s = {"Alice", 20, 95.5};
fwrite(&s, sizeof(struct Student), 1, fp);  // 把 s 写入文件
//       ↑数据地址   ↑每个元素大小        ↑元素个数

struct Student t;
fread(&t, sizeof(struct Student), 1, fp);   // 从文件读一个结构体到 t
```

二进制读写比文本读写快，而且不会有精度丢失。

### 文件定位函数

- `rewind(fp)` -- 把文件指针移回文件开头（rewind = 倒带）
- `fseek(fp, 偏移量, 起点)` -- 把文件指针移动到指定位置
  - 起点：`SEEK_SET`（文件头）、`SEEK_CUR`（当前位置）、`SEEK_END`（文件尾）
- `ftell(fp)` -- 返回当前文件指针的位置（离文件头多少字节）

```c
fseek(fp, 0, SEEK_END);     // 移到文件末尾
long size = ftell(fp);       // 获取文件大小（字节数）
rewind(fp);                   // 移回开头
```
