### 什么是数据类型？

C 语言里，不同的数据需要不同的"容器"来装。就像生活里：
- 整数（你的年龄）--> 用 `int`（整数类型）
- 小数（你的身高 1.75）--> 用 `float` 或 `double`（浮点类型）
- 单个字符（你的性别 'M'）--> 用 `char`（字符类型）
为什么要有数据类型？因为电脑内部，整数和小数的存储方式不同，告诉电脑数据类型，电脑才能正确存储和处理。

| 类型       | 存什么       | 占多大内存 | 举例                       |
|---|---|---|---|
| `int`    | 整数（没有小数点） | 4 字节  | 0, 1, -3, 100, 9999      |
| `float`  | 小数（精度较低）  | 4 字节  | 3.14, -0.5, 1.0          |
| `double` | 小数（精度更高）  | 8 字节  | 3.14159265358            |
| `char`   | 单个字符      | 1 字节  | 'a', 'Z', '0', ' ', '\n' |

`float` 和 `double` 的区别：`float` 大约能精确到小数点后 6-7 位，`double` 能精确到 15-16 位。

### 什么是变量？

变量就是一个有名字的盒子，里面可以放一个数据，而且以后可以换。**

```
+-----+
|  10 |  ← 盒子里现在装的是 10
+-----+
  ↑
  a    ← 这个盒子的名字叫 a
```

![5](/learn/c-language/charts/5.png)

使用变量分两步：**先声明（造盒子），再使用（放东西/取东西）**

```c
int a;        // 声明：造一个名叫 a 的盒子，只能装整数
a = 10;       // 赋值：把 10 放进盒子 a 里
int b = 20;   // 声明和赋值可以合写在一起
```

**命名规则：**
- 只能用字母、数字、下划线 `_`
- **不能以数字开头**（`1a` 不行，`a1` 可以）
- 不能用 C 语言的关键字（比如 `int`、`for`、`if` 不能当变量名）
- 区分大小写（`A` 和 `a` 是两个不同的变量）

### 什么是常量？

![4](/learn/c-language/charts/4.png)

**常量就是永远不变的值。** 一旦设定就不能改。

```c
#define PI 3.14159    // 定义符号常量 PI，以后代码里写 PI 就等于 3.14159
int a = 100;          // 100 也是一个常量（字面常量）
```

为什么用常量？比如你程序里到处用到圆周率 3.14159，写 10 次 3.14159，万一要改精度，就要改 10 处。如果用 `#define PI 3.14159`，以后改一处就行了。

### 运算符详解

**算术运算符（做数学运算的）：**

| 运算符 | 功能  | 举例       | 结果         |
|---|---|---|---|
| `+` | 加法  | `3 + 5`  | `8`        |
| `-` | 减法  | `10 - 3` | `7`        |
| `*` | 乘法  | `4 * 5`  | `20`       |
| `/` | 除法  | `10 / 3` | `3`（整数除法！） |
| `%` | 取余数 | `10 % 3` | `1`        |

**整数除法的坑（非常重要）：**
- `10 / 3 = 3`（不是 3.333，因为两边都是整数，结果自动砍掉小数）
- `10.0 / 3 = 3.333`（有一个是小数，结果就是小数）
- 想要精确结果，至少有一个数写成小数形式：`10 / 3.0`
**取余 `%` 的应用场景：**
- 判断奇偶：`n % 2 == 0` 就是偶数，`n % 2 != 0` 就是奇数
- 取个位数：`123 % 10 = 3`
- 判断倍数：`n % 7 == 0` 表示 n 是 7 的倍数
**赋值运算符 `=`（不是等于！）：**

```c
int a = 10;   // 把 10 赋值给 a
a = a + 5;    // a 原来是 10，加上 5，变成 15，再放回 a
a += 5;       // 上面的简写，a = a + 5 等价于 a += 5
a -= 3;       // a = a - 3
a *= 2;       // a = a * 2
a /= 4;       // a = a / 4
a %= 10;      // a = a % 10
'a'%2=1       //'a'是字符，先转换为ASCLL编码‘a’=97,97%2=1
```

`++` 和 `--`（自增自减）：

```c
int a = 5;
a++;    // a 变成 6（相当于 a = a + 1）
a--;    // a 变成 5（相当于 a = a - 1）
```

![6](/learn/c-language/charts/6.png)

类型转换：**

```c
int a = 3;
double b = 7.0 / a;   // 自动转换：a 自动变成 3.0 再算，结果是 2.333
int c = (int)3.9;      // 强制转换：直接砍掉小数，c = 3（不是四舍五入！）
```

### printf 和 scanf -- 输入和输出

**printf -- 在屏幕上显示信息：**

```c
printf("我的年龄是 %d 岁\n", 20);
//        格式控制符 ↑
//        %d 会被后面的 20 替换
//        输出：我的年龄是 20 岁
```

![7](/learn/c-language/charts/7.png)

![8](/learn/c-language/charts/8.png)

常用格式控制符：

| 符号     | 用途       | 举例                      | 输出         |
|---|---|---|---|
| `%d`   | 整数       | `printf("%d", 42)`      | `42`       |
| `%f`   | 浮点数      | `printf("%f", 3.14)`    | `3.140000` |
| `%.2f` | 保留 2 位小数 | `printf("%.2f", 3.14)`  | `3.14`     |
| `%c`   | 单个字符     | `printf("%c", 'A')`     | `A`        |
| `%s`   | 字符串      | `printf("%s", "hello")` | `hello`    |
| `\n`   | 换行       | `printf("A\nB")`        | A（换行）B     |

**scanf -- 从键盘读取用户输入：**

```c
int age;
scanf("%d", &age);
//     ↑    ↑
//     格式  &表示"把输入存到 age 的地址里"
//     输入一个整数，存到 age 变量中
```

**为什么 scanf 要加 `&`？**
你可以这样理解：scanf 需要知道"把数据存到内存的哪个位置"。`&age` 就是"age 这个变量在内存中的门牌号"。没有门牌号，快递员（scanf）就不知道往哪送。
**多个输入：**

```c
int a, b;
scanf("%d%d", &a, &b);  // 输入 3 5（中间用空格隔开），a=3, b=5
```

### 字符与 ASCII 码

电脑只能存数字，不能存字母。那怎么存字符呢？答案是：**给每个字符编一个数字编号**。这个编号表叫 ASCII 码。
常用 ASCII 码：
- `'A'` = 65，`'B'` = 66 ... `'Z'` = 90
- `'a'` = 97，`'b'` = 98 ... `'z'` = 122
- `'0'` = 48，`'1'` = 49 ... `'9'` = 57
- `' '`（空格）= 32
**大小写转换的技巧：**
- 大写转小写：`'A' + 32 = 'a'`（因为 'a'(97) - 'A'(65) = 32）
- 小写转大写：`'a' - 32 = 'A'`
